# 风格包 · 数据分析报告（data）

适用场景：数据分析汇报、财务 / 咨询数据演示、统计结果呈现。数值来源：Formal Stats、金融数据工具包、Gasper、数据分析工具包四套拆解报告（data.md）。四套样本的原生图表均为 0——本包的原生语言是"形状化数据图 + 原生表格"。

## 色板（四选一的成套方案，禁止跨套混搭）

| 方案 | 主色 | 底 / 辅 | 数据色逻辑 |
|---|---|---|---|
| 深蓝正式 | 深海军蓝 `#00041C`～蓝灰 `#465573` | 钢蓝 `#6E86B6`、白 | 单色深浅为主；多色仅限图表内部且 ≤5 色 |
| 紫单色咨询 | 亮紫 `#B219F6` | 纸白（微纹理）、同紫描边 | 全册单色：以深浅 / 实心描边区分系列，不引入第二色相 |
| 白底六色 | 黑（文字） | 白 + 浅灰 `#F3F3F3` | 固定六色序：`#E25447 → #EFCF7E → #3FCBB1 → #9ED0E6 → #6885CC → #8E7CC3`，所有图表 / 表头按序取色 |
| 科技蓝 | 亮青蓝 `#1BBBE9` + 深蓝 `#0B5394` | 暖白 `#F8F4F4`、浅灰 `#E1DDDD`、墨 `#202331` | 双蓝同色系：主色给强调，深蓝给次级；数据图以墨色线描 + 单蓝点睛，不铺多色 |

## 字体与字号梯度

- 字体：家族数 ≤2，标题与正文可双族分工。深蓝正式 = Titillium Web 类窄体无衬线（单族）；紫单色咨询 = 标题 Krona One 类全大写几何体 + 正文 Didact Gothic 类；白底六色 = Source Sans Pro 类（单族）；科技蓝 = 标题 Poppins ExtraBold 类全大写 + 正文 Barlow 类。
- 大数字 96 pt（统一取此值）；封面标题 48–55 pt；页标题 18–28 pt（紫单色系用 14 pt 全大写页眉式标题 + 内容区大字；科技蓝系 26 pt 标题 + 20 pt 小标题）；正文 12 pt（深蓝正式 / 科技蓝）/ 10 pt（紫单色咨询，高密度）/ 18 pt（白底六色，低密度汇报）；图注 8–10 pt。

## 页型配方

| 页型 | 构图配方 |
|---|---|
| 封面 | 按方案选一：深色满版 + 幽灵图表背景纹理 + 白大写标题（深蓝正式）；纸白 + 全页细线框 + 单色大标题 + 一个线框图形（紫单色咨询）；白底 + 色板造型装置（竖条 / 色块）+ 黑粗标题（白底六色）；暖白 + 四角斜切双蓝色块（科技蓝，角块为该方案内识别符） |
| 大数字页 | 单个 96 pt 数字居中 + 一行结论小字，全页再无其他元素（四套共识） |
| 图表页 | 一页一图，形状拼图（环 / 哑铃 / 甘特 / 滑杆）；标签直贴不用图例框；标题用结论式短句 |
| 表格页 | 原生表格。深蓝正式：深底细白线 + 半透明斑马行；紫单色咨询：主色满填表头 + 细主色网格 + 胶囊进度条；白底六色：行头列头双向用数据色、白底细灰线 |
| 框架页 | SWOT / 矩阵 / 画布类用细线分区 + 区名大写小字 |
| 时间线 | 细轴线 + 节点圆 + 交替标签 |
| 信息图页 | 主体居左 + 细线树状分行：图标白卡 + 数值 + 名称 + 一行注，菱形节点连接 |

## 组件语法

- 表格：无竖重线；表头与正文同字体，表头字号 = 正文字号 +2；数字右对齐（白底六色方案例外：数字左对齐，因行头在左）。
- 图表：环图线宽约直径 8%；哑铃 / 滑杆用方块标记三态（空心 / 半填 / 实心）表三系列；甘特条一律胶囊圆角。
- 固定图例位（可选）：白底六色方案可用左缘 6 色小方块竖排作全册图例列。

## 禁忌

- 不用 PPT 原生图表默认样式（本包图表一律形状化；重建时若为可编辑数据改用原生图表，必须套用所选方案色序并关掉默认样式）。
- 同一 deck 不出现两种数据色逻辑（单色系与六色系互斥）。
- 深色满版方案里表格不加实底色块，只用描边 + 半透明带。
- 正文页不用黄色高亮。
