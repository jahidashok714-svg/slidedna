# 风格包 · 产品发布（product）

适用场景：产品发布会、新品介绍、品牌提案。一页一个主视觉，元素密度远低于其他包。数值来源：发布计划、智能手表发布、轻奢产品发布三套参照拆解报告，字号按常规 10 in 画布计（三套共识：展示字特大 + 正文 10.5–12 pt 的强反差）。

## 色彩（三条路线，三选一）

| 路线 | 底 | 字 / 主色 | 点缀 |
|---|---|---|---|
| 渐变发布 | 整页渐变满版（橙红→黄，或红→粉流体；一册只用一个渐变家族） | 白字为主（实测白 : 黑 ≈ 6 : 1），黑字仅浅色页 | 无第三色，靠渐变本身 |
| 白底产品 | 白 / 浅灰 `#F5F5F7` | 黑（标题）、产品图本色 | 糖果点缀色 3–4 个：玫粉 `#DAA498` / `#FBD2CE`、珊瑚 `#FF7C6E`、蓝 `#007FE0`、琥珀 `#FFAB40`；只给装饰件、图标徽章与图表扇区 |
| 轻奢米白 | 象牙米白 `#F3ECE5` | 墨 `#191919` / `#262921` | 同色系深浅：陶土 `#D8C7B8`、深棕 `#7C583F`；禁止任何高饱和色，图表亦只用白 / 陶土 / 棕三段 |

## 字体与字号梯度

- 字体：渐变 / 白底路线为 DM Sans 类几何无衬线一族到底；轻奢路线例外——Jost 无衬线 + Gilda Display 衬线展示字双族（衬线展示字仅限轻奢路线）。
- 封面 / 章节展示字 72–96 pt（白底路线封面因右半让位产品图，实测上限 46 pt；轻奢路线封面为衬线特大，不钉 pt）；卖点名 / 页标题 24–27 pt 粗体（轻奢路线页题 20–29 pt）；大百分比 24–36 pt；正文 10.5–12 pt（三套一致）；眉题 14–16 pt 全大写。

## 页型配方

| 页型 | 构图配方 |
|---|---|
| 封面 | 渐变路线：渐变满版 + 眉题 + 巨字标题压至下缘出血 + 一枚细线箭头；白底路线：左右分栏，左黑粗巨字标题、右浅灰面板产品图，四角散点装饰件；轻奢路线：米白满版 + 陶土色块在页缘探头 + 居中大标题 + 一行小字副题，留白主导 |
| 章节页 | 满版底（渐变或图）+ 序号（03 式）+ 特大章节名；眉题行固定：左品牌名、右年份 |
| 产品页 | 产品图 / 样机占幅 ≥40%，从一至两边出血；文字侧只放"大题 + 一段"，或卖点行 |
| 卖点页 | 2–4 行卖点，彩色圆底图标徽章 + 粗体卖点名 + 一行说明 + 细下划线，左右交替 |
| 数据页 | 一图居中：饼 / 环图用本路线点缀色序，大百分比与扇区同色，名称 + 一行注配对；不用坐标轴图表。轻奢路线用三段环图（白 / 陶土 / 棕）横排，环下产品名大写 + 一段小字 |
| 产品对比页 | A / B 两列文字对位，中央一条竖轴串起陶土底图标方块作"对比脊"，列头陶土色块压字（轻奢路线样本做法） |
| 市场页 | 大数字 + 一行注（与数据包大数字页同构，底用本包路线底色） |
| 结尾页 | 与封面同底同题字规格，一句致谢 + 品牌名 |

## 组件语法

- 图标徽章：正圆满填点缀色 + 白 / 黑小图标，直径约与卖点名行高齐平。
- 眉题系统：全大写、字距略开，左品牌右年份，全册位置固定（轻奢路线代之以固定版心 + 发丝线框，路线内保留、跨路线不移植）。
- 细线语法（三套共识）：1 pt 级细线作结构语言——细线箭头、细下划线、全页发丝线框，按路线选一。
- 装饰件：白底路线的 3D 糖果几何只在页角散点出现，不进内容区（可选元素，易过时，慎用）；渐变路线无装饰件，渐变即装饰。

## 禁忌

- 不做白底 + 细边卡片的"汇报式"版式（那是商务 / 数据包的语言）。
- 一页一个主视觉，不堆三栏卡片。
- 渐变路线禁止再叠实色色块。
- 不用原生图表默认样式；产品图不加边框不加阴影，直接出血或压浅灰面板。
- 渐变底图不可编辑、换产品色即废：采"满版底 + 白巨字"的结构，不绑定样本的具体渐变图。
