# 风格包 · 商务汇报 / 路演（business）

适用场景：公司业务汇报、季度总结、商业计划与路演。数值来源：几何商务、商务咨询、科技市场调研路演三套参照拆解报告。画布基准 16:9。

## 色板（三选一系，一本 deck 只选一系，不混用）

| 角色 | 稳重系 | 活力系 | 路演系 |
|---|---|---|---|
| 主色 | 炭灰 `#363739` + 芥末黄 `#EFBC49`（深一号黄 `#D8A530` 备用） | 五色序列 `#DD5462 / #F4CB4D / #9CCA6D / #3FC1A0 / #4EB9E2`（固定顺序轮转） | 深蓝紫墨 `#110E24` + 亮青 `#00CADA`（单强调）+ 灰紫 `#69639C`（图形次色） |
| 底色 | 米白 `#F5F5EF`；深色页用炭灰满版 | 浅灰 `#F2F2F2` + 白；深色页用深炭 `#363636` 系满版 | `#110E24` 全册满版，面板用 `#211F33` 一档 |
| 中灰 | `#494F56` | — | — |
| 正文色 | `#3F3F3F`～`#434343` | 同左 | 白 / 浅灰（数字用青、图形用紫） |

用色纪律：
- 稳重系：芥末黄只出现在色块、节点卡、大数字三处。
- 活力系：五色必须按固定序列轮转（封面 → 表头 → 环图同序），不许乱序、不许增色。
- 路演系：青只给强调与数字，紫只给图形与扇区，白只给文字。
- 稳重 / 活力系浅底为主，深色满版页一册 ≤3 页（封面、大数字、结尾）；路演系全册深色到底，不混入浅底页。

## 字体与字号梯度

- 字体：无衬线，家族 ≤2——单家族（Barlow 或 Raleway 类）靠 Regular / Medium 字重分层，或双家族分工（Raleway Black / ExtraBold 展示 + Hanken Grotesk 类正文，路演系），禁止超过两族。无该字体时用微软雅黑替代并在构建报告注明。
- 封面标题 41–75 pt 粗体；大数字 75 pt（单数字可到 96 pt）；页标题 24–36 pt（路演系 26 pt）；小标题 16–18 pt；正文 16–18 pt（活力系）、12–13 pt（稳重系高密度页）或 10–12 pt（路演系数据密集页）；注释 9 pt。

## 页型配方

| 页型 | 构图配方 |
|---|---|
| 封面·稳重 | 左侧主色巨型半圆 / 弧形色块承载标题（占幅约 55%），右直角照片 + 同色小几何压角，角落放一个小母题符号 |
| 封面·活力 | 深色满版上 2/3 + 标题大写居中，下缘一排色板箭头 / 色条横贯全幅，把配色序列亮出来 |
| 封面·路演 | 深墨满版 + 细线电路走线装饰（只在边缘、中部留空），标题前青色三角标记，白字左对齐 + 一行浅灰副题 |
| 数据页·路演 | 深底上图表形状化：扇区按青-白-灰-紫色序，图标 + 标签直贴；KPI 页 = 原生表格（白细线、白字）+ 青色大数字排 + 紫系组合图 |
| 目录 / 议程 | 主色圆点编号 + 一行一议题 |
| 大数字页 | 深色满版，单个主色巨号数字居中 + 一行白字结论，下不放第二元素 |
| 数据页 | 图表全部形状化：环图横排（≤5 个）+ 对位说明栏（可压深色带）；柱 / 条用主色单色 |
| 表格页 | 原生表格：表头主色填充白字（活力系按列轮色），数据行浅灰斑马纹，细白线，无竖线强调 |
| 组织架构 | 主色矩形节点卡（圆头像 + 姓名 / 职务两行）+ 细线连接 |
| 团队页 | 圆头像 + 姓名 / 职务，主色圆环或色点点缀 |
| 结尾页 | 与封面同色块母题回扣，一句致谢 + 联系方式 |

## 组件语法

- 卡片：直角或极小圆角，主色满填或白底细边；无阴影。
- 数字徽章：主色圆 / 半圆 + 反白数字，与圆点母题成套使用。
- 表格：表头字 16–18 pt，正文行 12–16 pt。
- 图表：环图线宽约占直径 8–10%，环心数字 36 pt 级；标签直贴，不用图例。

## 禁忌

- 不用渐变填充做正文页底色。
- 不用原生图表对象的默认蓝灰配色（重建时若用原生图表，必须套用本包色序）。
- 不混两套色系；正文页不出现第二种装饰母题。
- 正文不用纯黑。
