# 风格包 · 教学课件（education）

适用场景：课堂教学课件、说课、培训讲义。数值来源：莫兰迪风说课模板 + 手绘笔记风课件模板两套拆解报告，已完成双套交叉验证。共同纪律：浅色底、点缀色 ≤3 个、装饰密度按封面 > 目录 > 章节 > 内容递减、圆编号徽章是本包的组件本体。

## 色板（两分支，二选一，不混搭）

| 分支 | 底 | 主色 / 点缀 | 墨色 |
|---|---|---|---|
| 莫兰迪低饱和 | 暖米白 + 浅块 `#E4E5D7` / `#D8E0CB` | 鼠尾草绿 `#A0B991`、米杏 `#D1CBB1` | 标题深橄榄棕（走主题引用，hex 未实测钉死，勿伪造数值） |
| 粉彩手绘 | 白色横线纸（笔记本底） | 粉彩三色 `#FEB8B3`（粉）/ `#FED58A`（黄）/ `#A6DFDA`（薄荷），官方色板实测 | 纯黑 `#000000` 线描（次级近黑 `#1D1D1B`） |

## 字体与字号梯度

- 标题字体按分支二选一（衬线宋体只是莫兰迪分支本体，不是全包共识）：
  - 莫兰迪分支：思源宋体 CN Heavy——封面 66 pt、目录"目录"60 pt、章节名 44 pt、目录条目 36 pt、章节数字 80–96 pt。
  - 手绘分支：Permanent Marker 手写体作展示字 + Comfortaa / Comfortaa Light 圆体作标题与正文；标题居中全大写。
- 正文：莫兰迪分支思源宋体或微软雅黑，众数 14 pt、重点行 16 pt；手绘分支 Comfortaa 小字号密排（显式 pt 未实测钉死，按 11 pt 级方向掌握，勿伪造数值）。
- 英文小字一律灰色、字号 ≤正文（莫兰迪分支做法，作推荐项）。

## 页型配方

| 页型 | 构图配方 |
|---|---|
| 封面 | 浅底 + 装饰成框：莫兰迪为四角有机形色块 / 线描植物对角呼应；手绘为黑线涂鸦环绕 + 三色点彩。居中轴：大标题 → 小字副题（莫兰迪另有点线、小标记、讲课导师落款） |
| 目录 | 莫兰迪：左标题区（约 1/3）+ 右条目列（圆徽章 + 双语条目 + 灰色英文注）；手绘：居中清单式 |
| 章节页 | 莫兰迪：Part 字样 + 巨号数字（80–96 pt）+ 章节名，装饰同封面；手绘无独立章节页，用阶梯推进页代替结构页 |
| 内容页 | 莫兰迪：2×2 图标文本网格（图标扁平单色、米杏 / 绿轮换）或左图右文，页中一条主色细线带圆点端；手绘：居中标题 + 居中正文 + 两侧人物插画，或手绘粗框阶梯流程 |
| 练习 / 作业页 | 标准页型（手绘分支样本 pp.18、19），标题 + 题目区，装饰收敛 |
| 结尾页 | 与封面同底同饰，大字居中 |

## 组件语法

- 编号徽章（两分支共识，形式随分支）：正圆 + 数字——莫兰迪为 `#D1CBB1` 圆 + 白数字；手绘为粉彩三色轮换圆 + 黑数字 + 手绘描边。
- 图标 / 插画：莫兰迪为扁平单色小图标，与标题同行左置；手绘为黑线涂鸦 / 人物，粉彩局部上色。
- 分隔线：莫兰迪为主色 0.75–1 pt 细线末端实心圆点；手绘为手绘箭头 / 粗框线。
- 内容组织：靠图标 + 文本块承载，正文不用原生表格（手绘样本的原生表格只出现在其附录日历页）。

## 禁忌

- 不用渐变、不用阴影卡片。
- 内容页不堆装饰（装饰只在结构页）。
- 不出现原生表格 / 图表的默认样式；教学中如需数据图，按数据包的形状化原则另行处理。
- 两分支的色与字体不跨分支混用。
- 英文注文必须写真实内容（样本里的语法错误英文是其粗糙处，不许照搬）。
