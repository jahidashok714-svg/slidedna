# 变量扩展 · 教学包学科扩展（education variables）

配合 `style_packs/education.md` 使用：教育包的通用页骨架（封面、提纲、学情、目标、过程时间轴、分层作业、反思结尾）全学科共用，差异只在每学科 2–3 种**招牌页**与通用页的内容口径。本文件覆盖初中/高中说课与课件场景的 9 个学科，配方全部用包内既有色板、字体与组件词汇书写，不新造视觉体系；生物一节提炼自已验收样板《光合作用的原理和应用》（莫兰迪分支，12 页），其餘学科按同一组件语法推演。

## 共用规则（先读）

- **版面基线**：16:9（13.33 × 7.5 in），内容页可用宽度 11.53 in；字号层级沿用包规范——莫兰迪分支标题思源宋体（章节名 44 pt 级、条目 36 pt 级）、正文众数 14 pt、重点行 16 pt；英文注文灰色、≤正文字号。
- **分支换算**：下文配方按莫兰迪分支书写；选粉彩手绘分支时版式结构不变，只换组件本体——圆徽章换粉彩三色（粉 `#FEB8B3` / 黄 `#FED58A` / 薄荷 `#A6DFDA`）轮换圆 + 黑数字 + 手绘描边，标题换 Permanent Marker 居中全大写，分隔线换手绘箭头/粗框线。
- **组件只用包内件**：圆编号徽章（莫兰迪 = `#D1CBB1` 圆 + 白数字）、扁平单色图标、主色 0.75–1 pt 细线末端实心圆点、浅块（`#E4E5D7` / `#D8E0CB`）、点缀色仅鼠尾草绿 `#A0B991` 与米杏 `#D1CBB1` 两系（大面积色带需白字时米杏换深米杏 `#A3976E` 保对比，此为样板实证修正）。
- **数据呈现**：不用原生表格/图表默认样式；百分比用形状条（条长与数值成正比并标注基准宽），曲线/坐标图用连接线逐段自绘并直标关键点，表格类内容用形状格逐格拼。
- **口径纪律（全学科）**：课时分配合计 = 一课时（40 或 45 分钟，建册先定死）；学情百分比合计 100%，且学情分类、过程时间轴、分层作业三处互指对应；凡虚构/示例数字在落点页页脚或面板注标「展示数据」；图、表、材料一律编号（图 1、表 1…）并配一句结论性图注。
- **装饰纪律**：装饰密度封面 > 目录 > 章节 > 内容递减；招牌页属于内容页，只许页眉圆点细线与徽章，不回加封面级装饰。

## 一、语文

### 招牌页

**1. 文本细读批注页**
- 版式：左右分栏——左 55% 原文区，右 45% 批注列。
- 原文区：浅块底卡（`#E4E5D7`）内排原文段落，宋体 16–18 pt、行距 1.6；待批注的词句加鼠尾草绿下划线或米杏底纹，句首外侧留 0.3 in 标号位。
- 批注列：3–4 条批注纵排，每条 = 圆徽章编号（与原文标记序号一一对应）+ 批注小题（16 pt 粗）+ 解读正文（14 pt，2–3 行）。
- 口径：原文逐字录入并在卡底注篇目出处；批注条数 = 原文标记数，多一个少一个都不许；引文中的标点从原文。

**2. 课文结构 / 情感脉络图页**
- 版式：上图下注——上方横向链路占页高约 45%，下方关键句引文卡一排。
- 链路：包细线（圆点端）横贯 11.53 in，按段落群分 4–5 个节点，节点 = 浅块药丸（结构名 16 pt 粗）+ 药丸下一句概括（14 pt）；线条上方以小字标注情感词（如「沉郁」「昂扬」），情感转折点在对应节点正上方加一枚米杏圆点放大标记。
- 引文卡：每节点正下方挂一张白底细边卡，卡内一句原文关键句（14 pt）+ 出处段号小字。
- 口径：节点数 = 划分的段落群数，划分依据（时间/场景/情感）须在页眉副题交代一句；引文逐字。

**3. 诗词意象页**（古诗文课题用，替代细读页）
- 版式：中央诗篇区 + 下方三卡。诗篇原文居中排（宋体 20–24 pt，行距 1.8），作者与出处小字居其上。
- 下方三张等宽意象卡（浅块底，绿杏轮换顶条）：意象名（16 pt 粗）+ 画面一句 + 情感一句，各 14 pt。
- 口径：意象必须能在诗句中指出对应字句，卡底小字注「出自第 × 句」。

### 通用页适配

提纲条目直接用学习环节命名（初读感知 → 品读赏析 → 研讨交流 → 拓展迁移）；学情页换「阅读基础三层」（词汇识记 / 文本理解 / 赏析表达）以形状条呈现并下挂对策；教学目标 2×2 网格换语文学科核心素养四维（语言建构与运用、思维发展与提升、审美鉴赏与创造、文化传承与理解），图标沿用包内扁平单色件轮换。

### 禁忌

原文与引文一字不许改、一处出处不许编；原文区只用正文字体排版，不把课文做花字/艺术字变形来"显古风"。

## 二、数学

### 招牌页

**1. 公式推导链页**
- 版式：纵向中轴链，4–6 步，每步一行贯通全宽。
- 每步三段：左圆徽章步骤号 → 中公式行（18–20 pt，等号在全页范围内对齐成一竖列，用等宽占位逐行校准）→ 右依据注（灰色小字，如「两边同除以 a」「因式分解」）。
- 步与步之间以细线小箭头连接；最后一步整行换鼠尾草绿浅块底（`#D8E0CB`）作结论行，公式加粗。
- 口径：每步变形必须等价，系数、正负号、指数逐项复核；字母斜体与下标写法全册统一（如 x₁、aₙ）。

**2. 几何图形页**
- 版式：左 50% 图形区，右 50% 文字区。
- 图形区：形状自绘几何图——直线用连接符按坐标精确落点，顶点字母 12–14 pt 紧贴顶点外侧，直角处加小方标，等长边加等量短刻度线，辅助线一律虚线并与实线区分。
- 文字区：上「已知」卡、下「求证」卡（浅块底），卡下挂辅助线说明一条（圆徽章领起）。
- 口径：图形边长/角度比例与题面数据一致，不许示意性失真到误导读数；标注字母与题面符号一一对应，图上出现的字母文字区必须同名引用。

**3. 函数图像页**
- 版式：左 55% 坐标区，右 45% 性质列。
- 坐标区：双轴形状自绘（轴线 1 pt、箭头端），网格用最浅细线（`#E4E5D7` 级）等距铺；曲线用自由曲线/连接线逐段绘出；关键点（顶点、交点、截距）用主色圆点标记并直标坐标（12–14 pt）。
- 性质列：圆徽章编号 3–4 条（开口方向 / 对称轴 / 单调区间 / 最值），每条一行结论。
- 口径：关键点坐标须由解析式算出后回填，两处（图上直标与性质列）数值必须一致；坐标轴刻度等距且标注完整。

### 通用页适配

学情页换「运算 / 概念 / 推理」三维诊断形状条；过程时间轴按复习引入 → 探究新知 → 例题示范 → 变式练习 → 小结分段，段宽 ∝ 时长；分层作业固定三层（A 基础题 / B 变式题 / C 探究题）与学情三维对应；板书页沿用生物板书骨架，主板放推导链、副板放图形（见生物节板书配方）。

### 禁忌

公式与几何图一律形状/文本自绘、保持可编辑，禁止贴截图或图片充数；函数图禁止用原生图表代替（刻度与曲线不可控，必失真）。

## 三、英语

### 招牌页

**1. 词汇卡页**
- 版式：2 行 × 3 列词汇卡网格（卡宽约 3.6 in），六词一页为限。
- 每卡自上而下：单词展示字（24–28 pt）→ 音标（灰色小字）→ 词性徽章（小圆角块，绿杏轮换）+ 中文义项（14 pt）→ 例句一行（14 pt，目标词加鼠尾草下划线）。
- 口径：音标、词性、义项按课标词表核对；例句须语法正确且难度贴合学段，不自造病句。

**2. 语法结构图页**
- 版式：上结构图、下步骤链。主句横带居中（浅块长条，主干成分在带内以板块分隔：主语 / 谓语 / 宾语板块用绿、杏、灰三系区分，修饰成分以细线下挂小块标注定语/状语）。
- 下方拆解步骤链：圆徽章 3 步（找谓语 → 定主干 → 辨修饰），每步一句操作口诀（14 pt）。
- 口径：例句的成分划分须有唯一正确答案，存争议的句子不选；结构图板块数 = 实际成分数。

**3. 对话情境页**
- 版式：左 40% 情境图（照片以米杏画框融入，或手绘分支用人物插画），右 60% 对话气泡列。
- 气泡：2–4 轮，左右交替浅块气泡（说话人一侧绿系、另一侧杏系），气泡内对话 14–16 pt；每轮气泡下方小字注本轮功能句型，目标句型部分加鼠尾草下划线。
- 口径：对话须完成一个完整交际任务（问路、购物、邀请等），轮次与任务步骤对应；人名用课本常见名，不影射真人。

### 通用页适配

教学目标 2×2 网格换英语学科核心素养（语言能力、文化意识、思维品质、学习能力）；过程时间轴按热身 → 呈现 → 操练 → 产出 → 作业分段；提纲与页眉的英文注文必须是真实且语法正确的英文（包禁忌，参照样本的错误英文是其粗糙处，不许沿用）；学情页可加「词汇量 / 听说 / 阅读」三维形状条。

### 禁忌

英文零语法错误容忍：注文、例句、对话在交付前逐句校读；音标不许用汉语拼音或谐音字代替标注。

## 四、物理

### 招牌页

**1. 实验装置与步骤页**（与生物实验页同骨架，见生物节第 1 种）
- 版式：左 45% 装置图，右 55% 步骤徽章列（4–5 步），页底数据记录带。
- 装置图：形状自绘器材轮廓（不贴照片替代示意），每个部件以包细线（圆点端）引出标注（名称 12–14 pt），标注线不交叉。
- 数据记录带：形状格逐格拼的记录表（行 = 测量次序，列 = 物理量 + 单位），空格留待课堂填写，表头行浅块底。
- 口径：装置标注与实物连接关系一致；单位全册统一用 SI 制，同一量不许两种单位并存。

**2. 受力 / 过程分析图页**
- 版式：中央偏左受力图，右侧过程链。
- 受力图：物体以方块/圆表示，力以箭头矢量绘出，箭头长度与力的大小成正比（页注写明比例），箭头旁直标符号（F、G、f、N…，下标规范）；坐标方向箭头置于图角。
- 过程链：右侧纵列 3 个状态小图（同一物体的三个时刻，缩略复用主图元素）+ 每状态一句说明（14 pt），状态间细线箭头连接。
- 口径：矢量方向、相对长度、作用点三项逐一核对；分力/合力不许同图混画而不加说明。

**3. 规律曲线页**（骨架同数学函数图像页）
- 坐标图形状自绘，曲线外加两个含义标注框：斜率含义、面积含义，各以引线指向曲线对应部位（引线用包细线圆点端）。
- 口径：标注的斜率/面积物理含义须与图像纵横轴量纲推导一致（如 v–t 图面积 = 位移）。

### 通用页适配

学情页固定增加一条「前概念误区」（写出本课最常见的错误前概念及人数占比，形状条）；过程时间轴须单列实验与数据处理段；教学目标 2×2 网格中一格固定给「科学探究」；反思页加一条「实验达成度」。

### 禁忌

矢量箭头的方向与相对大小不许随手画（画错即科学性错误）；电路图符号必须按国标形状自绘，不贴网络图片。

## 五、化学

### 招牌页

**1. 实验现象与方程式页**
- 版式：左列步骤与现象，右区方程式。
- 左列：圆徽章步骤 3–4 步，每步一行「操作 → 现象」，现象关键词以米杏底纹标出。
- 右区：主方程式居中大字（20–24 pt）；反应条件（点燃 / 加热 / 催化剂）小字置于等号正上方，气体 ↑、沉淀 ↓ 符号紧跟产物；方程式下方挂「现象—结论」对应徽章 2–3 条。
- 口径：方程式必须配平且条件、符号齐全正确（交付前按元素逐个点数）；现象描述与步骤一一对应，不写方程式里看不出的现象。

**2. 微观示意页**
- 版式：左「反应前」、右「反应后」两区，中间反应箭头；右上角图例。
- 两区内以圆球组合表示分子/离子（同种原子同色同径）；图例逐项对应（圆样 + 元素名）；用色限包内绿、杏、灰及深浅两档，不够分时以圆径大小再分一维。
- 口径：反应前后各元素原子个数必须守恒且与本课方程式计量数一致（画完按方程式点数复核）。

**3. 物质转化关系图页**（推断/复习课用）
- 版式：全页框图网络：物质节点 = 浅块药丸（名称或代号 16 pt），转化关系 = 带箭头细线，箭头上方小字标反应条件；未知物质节点用字母代号圆徽章样式区别于已知节点。
- 口径：每条箭头须真实可发生且条件标注正确；节点数 ≤ 8，超过则拆页。

### 通用页适配

学情页换「宏观现象 / 微观构成 / 化学符号」三重表征诊断；过程时间轴单列实验安全提醒段（可并入导入段并在时间轴段内加注）；反思页固定增加「实验安全与废弃物处理」一条；板书页主板放方程式与现象对照、副板放微观示意缩略（沿用生物板书骨架）。

### 禁忌

方程式配平、条件、↑↓ 符号零错误容忍；危险操作（如浓硫酸稀释、加热制气）的步骤顺序不许写反，且该页必须带安全提示注。

## 六、生物（样板已验证：人教版必修一《光合作用的原理和应用》说课，莫兰迪分支）

### 招牌页（以下三页均为样板实测落地的做法，直接照建）

**1. 探究实验步骤页**（样板 S9）
- 版式：左图右文——左 42% 实验照片以米杏画框融入版式，图下配图注（「图 1」+ 一句结论性说明）；右 58% 步骤列。
- 步骤列：5 步，圆徽章编号绿杏交替贯穿（与提纲徽章同一母题），每步 = 步骤名（粗）+ 操作说明同行排（14 pt）。
- 页底一条变量控制注，写明自变量 / 因变量 / 无关变量三项口径。
- 口径：步骤数与过程时间轴中实验段（样板为 12 分钟）互指；图注编号与全册图序一致。

**2. 板书设计页**（样板 S10）
- 版式：整页一块深鼠尾草绿板面（圆角矩形）模拟黑板，内部主副两区以细线分隔。
- 主板（左约 62%）：顶部课题居中；正文两列对照（如光反应 / 暗反应），行项目对齐排布（场所 / 条件 / 物质 / 能量四行）；底部总反应式通栏一行；两列交界处加一句「咬合注」点明联系。
- 副板（右约 38%）：绘图区——曲线用连接线逐段自绘（如光合速率曲线），关键点（如光饱和点）直标名称与坐标含义，双轴带箭头与轴名；图下关键词一行收束。
- 配色：板面内文字以粉笔白为主、杏黄作强调（标题与关键式），不引入板外颜色。
- 口径：板书内容 = 本课知识结构全量（讲授时能逐行板书复原）；曲线关键点位置与实验/数据页口径一致。

**3. 教材内容结构图页**（样板 S3）
- 版式：左文右图或上文下图，结构图占页约一半。
- 结构图：中心节点（本节名，绿块）→ 包细线连接 → 3 个分支板块（浅块），每板块下挂 2 条子项（14 pt）。
- 页底承上启下链：三段药丸横排（前置知识 → 本节〔鼠尾草绿高亮〕 → 后续章节）+ 段间箭头。
- 口径：分支数 = 教材实际小节数，子项用教材小标题原词，不自创概括词替代。

### 通用页适配（样板已验证口径）

提纲用莫兰迪目录配方：左 1/3 浅绿标题带（「目录」大字 + 灰色英文注 + 圆点细线），右列条目 = 圆徽章 + 条目名 + 右对齐灰色英文注，共 7 条目对应说课七部分；学情三类学生以形状条呈现（条长 ∝ 百分比，基准宽在面板注写明），每类下挂教学对策，并与分层作业 A/B/C 三层逐项对应；教学目标用 2×2 图标文本网格承载核心素养四维（图标扁平单色、绿杏轮换，每维两条可测目标）；过程时间轴段宽严格 ∝ 时长（段宽 = 分钟 × 11.53 ÷ 总分钟），段内直标分钟数，下方等宽活动卡与时间轴逐段对应，底部合计带写明总时长。

### 禁忌

米杏底白字对比偏弱（样板实证）：圆徽章的米杏底白数字为包规范组件本体可保留，但卡带、标签类大面积米杏底白字必须换深米杏 `#A3976E`；实验照片上零文字叠加（图注一律置于框外）。

## 七、历史

### 招牌页

**1. 大时间轴页**
- 版式：全宽横轴横贯 11.53 in，轴下时期色带，轴上事件卡上下交替。
- 横轴：包细线，按年份严格成比例落点（点位 = 年份 × 轴宽 ÷ 全距），事件节点 = 主色圆点 + 年份展示字（16–18 pt）；事件卡（名称粗 + 一句意义 14 pt）沿轴上下交替排，避免同侧拥挤。
- 时期色带：轴下以浅块色带分 2–3 个时期，色带内小字注时期名与起讫年。
- 口径：节点位置只由年份决定，不许为排版均匀人为挪位；相邻事件年份差过小时用引线外拉卡片，点位不动。

**2. 史料研读页**（版式骨架同语文细读页）
- 版式：左 50% 史料卡，右 50% 设问链。
- 史料卡：浅块底 + 左侧竖线引用边，史料原文（14–16 pt），卡底出处行小字（书名 · 作者/编者 · 卷次篇名）三项齐全；关键词句加鼠尾草下划线。
- 设问链：圆徽章 3 问纵列——表层信息（史料说了什么）→ 深层解读（为何如此记载）→ 价值判断（可信度/史料价值），每问一行任务表述。
- 口径：史料须真实可查、逐字录入、出处可回溯；节选须标省略号，不许改字凑意。

**3. 历史地图要点页**
- 版式：左 55% 地图区，右 45% 要点列。
- 地图区：形状简化绘出疆域轮廓/行军或贸易路线（路线用带箭头细线 + 沿线节点圆点），右下角图例（线型/点型各一行说明）。
- 要点列：圆徽章 3 条（方位范围 / 关键地点 / 路线走向），每条一句。
- 口径：疆域范围按教材地图口径绘制，不自创画法；古今地名并注（古名在前、今名括号注）。

### 通用页适配

教学目标 2×2 网格从历史核心素养五维中取四（唯物史观、时空观念、史料实证、历史解释；家国情怀并入结尾反思页专条）；学情页换「时序概念 / 史料阅读 / 因果分析」三维形状条；过程时间轴的分段命名用史料研读课环节（导入设疑 → 史料研习 → 论从史出 → 迁移评价）。

### 禁忌

史料、年份、人名零编造：凡上页的历史事实三要素必须可溯源；地图不使用来源不明的网络疆域图（必须形状自绘且按教材口径）。

## 八、地理

### 招牌页

**1. 地理图表判读页**
- 版式：左 55% 图区，右 45% 判读链。
- 图区：统计图按数据包形状化原则重绘（形状条/连接线 + 数值直标），或等值线示意图（线条疏密与弯曲方向按规律绘，关键线直标数值）。
- 判读链：圆徽章四步纵列——读图名 → 读图例与单位 → 读数值与趋势 → 得结论，每步一行；链底结论卡（浅块底）写本图结论一句。
- 口径：图中每个数值与源数据逐一对应；等值线数值沿线标注且递变方向正确。

**2. 区域地图要点页**（骨架同历史地图页，用色与图例从地理口径）
- 版式：左 55% 区域轮廓图（形状简化轮廓 + 经纬线示意两条 + 方位标置于图角），右 45% 要点列。
- 要点列：圆徽章 4 条固定序——位置 → 地形 → 气候 → 产业/人地关系，每条一句结论。
- 口径：轮廓可简化但相对方位、邻接关系、海陆位置不可变形到误认；经纬度数值标注与教材一致。

**3. 原理示意页**（水循环 / 大气环流 / 岩石圈物质循环等）
- 版式：中央循环链路图占页约 60%，四周环节注。
- 链路：4–6 个环节节点（浅块药丸，环节名 16 pt）以带箭头细线连成闭合环路，箭头方向即物质/能量流向；每节点外侧挂一句注（14 pt）说明该环节过程。
- 口径：环路必须闭合且箭头方向全对；环节数 = 教材原理图的环节数，不增删环节凑版式。

### 通用页适配

教学目标 2×2 网格换地理核心素养四维（人地协调观、综合思维、区域认知、地理实践力）；学情页固定含「读图能力」一层（看不懂图例/不会读数值/不会得结论三档形状条），与分层作业对应；过程时间轴可含读图实验或校园气象观测等实践段，段名写明实践内容。

### 禁忌

等值线递变、风向与洋流箭头、锋面符号这类有唯一正误的元素零容忍画反；统计图必须形状化重绘，不贴原生图表默认样式（包禁忌在本学科最易破，交付前专项检查）。

## 九、思想政治

### 招牌页

**1. 议题式教学情境页**
- 版式：左 45% 情境材料卡，右 55% 议题链。
- 材料卡：浅块底，时事/案例材料原文（14 pt），卡底来源行小字（媒体/文件名称 + 发布日期）两项齐全。
- 议题链：总议题展示字一行（20–24 pt 粗）置右列顶部；其下圆徽章 2–3 个子议题纵列，每个子议题 = 议题句 + 探究任务一行（14 pt）。
- 口径：材料来源真实可查、日期在页上明示（时效性自证）；议题表述用教材规范提法。

**2. 观点辨析页**
- 版式：左右对置双卡 + 中缝 + 页底结论带。
- 双卡：观点 A（绿带顶）/ 观点 B（杏带顶）对置，中缝用包细线圆点分隔（同教法学法页母题）；每卡内 = 观点原句 + 其下「辨析三行」（合理之处 / 认识误区 / 规范表述，各一行）。
- 结论带：页底通栏浅块带，一句规范结论收束。
- 口径：被辨析的观点须是学生常见误区的原样表述；「规范表述」行逐字对照教材原文，不 paraphrase。

**3. 知识体系建构页**（骨架同生物教材结构图页）
- 版式：三级框图——单元中心节点 → 板块节点（3–4 个）→ 要点子项（每板块 2–3 条），细线连接逐级下挂。
- 易混易错点以米杏虚线框在图侧单独圈注（1–2 处），框内写辨别要点一句。
- 口径：层级关系从教材目录，不自创分类；虚线框数量 ≤ 2，多了说明体系本身没理清，先回教材。

### 通用页适配

教学目标 2×2 网格换政治学科核心素养（政治认同、科学精神、法治意识、公共参与）；学情页换「时政知晓度 / 概念混淆点 / 价值判断困惑」三维；过程时间轴按议题式环节分段（呈现情境 → 辨析议题 → 价值引领 → 践行小结）；反思页固定增加「价值引领落地情况」一条，与亮点/不足并列。

### 禁忌

规范表述零改字：党和国家机构名称、会议与文件名称、政策提法逐字核对，不许自创简称或换同义词；时事材料不许用无来源、无日期的截图充数。
