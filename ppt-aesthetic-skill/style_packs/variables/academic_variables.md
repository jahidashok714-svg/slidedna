# 变量扩展 · 学术包学科扩展（academic_variables）

本文件是 `academic.md` 的学科变量层，不另建视觉体系。使用顺序：先按学术包锁定白底深蓝顶会风、结论式标题、章节眉题、青色标题下短线、图注制和零阴影纪律，再按研究证据的生成方式选择一类学科扩展。一册只设一个主类；跨学科课题只借用另一类的单个页型，不混用其结论口径。

## 共用基线

- 画布 13.33 × 7.5 in；内容左基线 0.62 in，右界对称；页标题 28 pt 粗体，眉题 10.5 pt 灰，正文 12.5–13.5 pt，图注 10.5 pt 灰，文件内字体统一写微软雅黑。
- 主色深蓝 `#0F2A4A`、品牌蓝 `#1F5FA8`、辅助青 `#2EA8C0`、唯一强调橙 `#D55E00`、卡片浅底 `#F4F5F7`、描边 `#CFD9E0`、正文 `#333D47`、次级灰 `#5A6B7D`。图表只用学术包 Okabe-Ito 数据色板，常规双系列优先蓝 + 橙。
- 每页必须有章节眉题和结论式标题。图、表全册连续编号；图注和表注必须自含研究对象、比较口径、关键定义、数据来源四项中与该页有关的内容，不能只写“实验结果”。
- 通用页仍按学术包配方：封面、提纲、背景双卡、结论与编号计划、深蓝谢谢页。变量层只替换或强化“证据页”，不改变封面层级、目录胶囊、卡片、结论带和图注格式。
- 样例、虚构或未核实材料必须就地标“示例 / 展示数据 / 待核”，不得用看似真实的机构、档案号、伦理号、样本量或引文补齐空白。

## ① 理工科实验型（已验证）

适用于算法、工程、计算机、物理、材料等以系统、实验和可复算指标形成证据的研究。已沉淀参照为虚构点云重建组会样板：五模块方法流水线、双指标主结果、消融表、失败案例三列对照及其与后续计划的编号互指。

### 招牌页 1：方法框架流水线页

- **构图配方**：页面中部放一个 1 pt 描边、无阴影的大容器；内部按处理顺序横排 4–6 个模块框，框左上角加序号点标。输入与预处理用品牌蓝浅档，核心变换用蓝色/青色两档，输出或最终预测用深蓝实底白字；模块之间用约 2.25 pt 细箭头连接，箭头上方标实际传递的数据，如“深度 + 位姿”“特征 $F_t$”“融合体素”。
- **反馈与对照**：若训练期存在校验、反馈或迭代，用虚线回路从后级模块返回被调整模块，并在线旁注“仅训练期”或触发条件；不要把虚线画成主数据流。
- **图注**：编号为“图 N”，写清输入、核心改动、输出及“与基线的结构区别”；本页标题直接写核心改动带来的结论，不写“系统架构图”。

### 招牌页 2：主结果双图页

- **构图配方**：两个指标单位相同且量纲可比时用一张分组图；单位不同、方向相反或量级悬殊时，左右并置两张原生图。基线用蓝系深浅分档，本文方法全图只用橙色；数据标签 12–13 pt 粗体直标，图例移入图内。
- **标注**：每张图题行右端加“本文 X · 最优 / 最低”短标注；页底放浅蓝结论带，依次写绝对差、相对变化和一句话解释。坐标轴必须带单位，越高越好或越低越好要在轴题或图注中明示。
- **口径**：图注写数据集/场景数、划分方式、平均方式和随机种子口径，如“12 个测试场景平均”；两图若使用不同子集，禁止共用一个含混图注。

### 招牌页 3：消融表与失败案例对照页

- **消融表配方**：原生表格第一行放完整模型，浅蓝底高亮并加左侧 4 pt 橙竖条；后续每行只移除或替换一个模块；除原始指标外，另列相对完整模型的 $\Delta$ 列。表注写基准行、测试集和重复运行口径，结论带点名贡献最大与贡献最小的模块。
- **失败案例配方**：三列依次为“问题现象｜原因分析｜改进办法”，三行各给一个案例，行首用 A/B/C 橙色案例签；底部用深蓝整行横带收束共同根因。后续计划页的编号必须逐项回指案例编号，不能另起一套无关计划。
- **设置页底线**：在主结果之前用 2×2 设置卡交代数据划分、输入与预处理、指标定义、公平口径，关键参数就地深蓝加粗。

### 通用页适配要点

- 提纲按“问题定义 → 相关工作 → 方法 → 实验设置 → 主结果/消融 → 失败与计划”组织，章节说明写每章要回答的问题。
- 背景双卡分别写“现有瓶颈”和“可检验的问题定义”，卡底加“问题 → 对应实验页码”索引带。
- 相关工作页用小表比较输入、核心机制、处理方式和局限，本文行高亮；结论页不重复贴主图，只保留关键增量、失败边界和下一阶段编号时间线。

### 本类特有禁忌

**禁止把不同数据划分、不同脚本、不同随机种子或最佳单次运行混在同一比较中冒充公平对比；口径不一致时必须拆图或在图注中逐项标明。**

## ② 医学 / 生命科学统计型

适用于队列、病例对照、临床试验、诊断准确性、组学与真实世界研究。核心证据不是单个“显著结果”，而是研究人群如何形成、结局如何判定、效应量及其不确定性是否可追溯。

### 招牌页 1：队列与分组流程页

- **构图配方**：左侧约 68% 放纵向或横向主流程，节点依次为“源人群 → 符合入选 → 排除 → 最终入组 → 分组/暴露 → 随访完成 → 纳入分析”；每个节点框内必须同时写阶段名和 `n`。右侧约 32% 放排除原因清单，各原因与对应 `n` 逐项对齐；若为随机试验，再在分组节点下分出各组人数、未接受分配干预人数和失访人数。
- **时间口径**：流程下方加一条浅底口径带，写清时间零点、入组窗口、随访截止日/数据锁定日、结局观察窗；观察性研究用“暴露分组”，不得把观察分组画成“随机分配”。
- **病例流程**：单病例或病例系列改为时间线：发病/就诊 → 关键检查 → 诊断判定 → 干预 → 转归；日期一律用相对时间（如“第 3 天”），不出现姓名、病案号、精确出生日期、面部照片等可识别信息。

### 招牌页 2：基线与样本口径表页

- **构图配方**：用原生表格做“表 1”：第一列为特征，后续每组一列，末列可放总样本；列头必须写组名与分母 `n`。连续变量按分布写均值 ± 标准差或中位数（四分位距），分类变量写 `n (%)`，每行缺失数放特征名下方小字或单列“缺失 n”。
- **呈现纪律**：基线表默认不放组间 p 值，不用显著性星号制造“基线不平衡”结论；标准化差异若使用，须在表注给出计算口径。百分比的分母若逐行不同，必须逐行标分母，不能只在表头写总 n。
- **口径带**：表下结论带只写样本代表性、关键缺失和潜在偏倚，不把基线差异写成干预效果；另列分析集定义，如全分析集、符合方案集或完整病例集。

### 招牌页 3：效应量与不确定性森林图页

- **构图配方**：左侧约 30% 列结局或亚组名，中部约 45% 用原生形状画点估计与 95% 置信区间横线，右侧约 25% 用文字列逐行写“效应量（95% CI）”和精确 p 值；中部设清晰的无效线（RR/OR/HR 为 1，均值差为 0），主结局点用橙色，次要结局用蓝系。
- **尺度与排序**：比值指标用对数尺度并在轴上标 0.5、1、2 等易读刻度；亚组按预先定义的临床顺序排列，不按 p 值从小到大排序。探索性亚组在图题或图注标“探索性”，交互作用 p 值单列，不以“某一亚组显著、另一亚组不显著”代替交互检验。
- **图注**：必须写模型类型、调整变量、分析集、缺失处理、效应方向（如“数值越低越好”）和多重比较处理；显著性星号只能作精确数值后的辅助，不能替代效应量、95% CI 和分母。

### 通用页适配要点

- 提纲按“研究问题 → 队列与方法 → 主要结果 → 敏感性/亚组 → 局限与计划”组织；背景双卡分别写临床/科学空白与本研究设计能回答的范围，并在背景页明示 PICO/PECO 的对象、干预或暴露、对照和结局。
- 每张数据页页脚或表注中按实际具备情况标注：伦理审查机构与批准号、知情同意或豁免、试验注册号、数据截止日、数据版本。未取得的编号写“待补录”，不得编造示例号充作真实信息。
- 结论页先写主结局的绝对差异与相对效应，再写 95% CI 和临床意义；计划页逐项回指偏倚来源、缺失机制、样本量不足或结局判定问题。

### 本类特有禁忌

**禁止只报“p < 0.05”或显著性星号而隐藏效应量、95% CI 与分母 n，也禁止据此把统计关联直接写成疗效或因果结论。**

## ③ 文科文本 / 史料型

适用于文学、历史、哲学、语言学及思想史研究。核心证据是可核验的文本位置、版本关系和解释链；页面应让读者分清原文、转述、研究者推论三层。

### 招牌页 1：史料研读页

- **构图配方**：左栏约 38% 放史料影印占位框或经授权的局部图版，无图版时用虚线占位框并写“图版待授权”；中栏约 34% 放录文，逐段加段号，异体字、漫漶和补字用编辑符号标明；右栏约 28% 放来源卡与释读 callout。
- **来源卡**：逐项写题名、作者/形成者、形成年代、版本或载体、收藏机构、索书号/档号、页码或叶码、查阅日期。影印件看不清的字标“□”，拟补字用方括号，无法确认的读法在图注标“待核”。
- **解释分层**：页底结论带分三段呈现“原文可证｜作者据此释义｜尚属推论”，三者不能混写成一个确定结论；二手转述必须标转述来源，不得排成原始引文样式。

### 招牌页 2：文本细读与观点脉络图页

- **构图配方**：左侧约 42% 放 2–3 段关键原文，每段带章节、页码或行号定位，并用浅蓝底标出被分析的词句；右侧约 58% 放观点脉络图：深蓝框写核心命题，向下或向右连出“论据 1 / 论据 2 / 限定条件”，再汇入结论框，争议点用橙色小签标出。
- **连线语法**：实线箭头只表示文本中明确的论证推进；“转折”“让步”“回应反驳”写在线旁；研究者重构的逻辑关系用虚线，并在图注注明“研究者整理”。节点文字用短句，不把整段释义塞入框内。
- **细读 callout**：右侧脉络图旁或下方放 2–3 条竖色条 callout，分别解释关键词义、修辞动作和上下文限制；每个判断必须能回指左侧段号。

### 招牌页 3：版本对比表页

- **构图配方**：原生表格第一列为“文本单元/段落定位”，其后每列一个版本，列头写版本简称、年代、底本或见证类型；单元格放关键异文，不整页复制大段文本。实质异文用深蓝粗体，共同但易误读处用青色小点标示，最关键的一处差异才许用橙色点标。
- **校勘口径**：表注写清底本、校本来源、标点与异体字处理原则、符号凡例，如“〔 〕为据他本补入”“〈 〉为衍文拟删”；版本年代或源流未定者标“待考”，不得用表格顺序暗示确定的传承关系。
- **结论带**：先写异文改变了什么意义、年代判断或作者归属，再写仍不能据此确定的部分；不能把“文字不同”直接等同于“某版错误”。

### 通用页适配要点

- 提纲按问题链组织：“问题提出 → 史料与版本 → 文本细读 → 学界争论 → 结论与待查材料”，每章说明要解决的争议，不按材料年代机械罗列。
- 背景双卡分别写“已有解释及其分歧”和“本研究新增材料或新读法”；关键术语首次出现时给出一句定义及原文用例位置。
- 结论页的每个判断都带适用范围，如“就甲本而言”“在现存三种见证中”；计划页逐项对应待查档案、待核版本或待访谈对象。口述史材料另须标访谈同意、录音编号、转录校对状态和受访者匿名方式。

### 本类特有禁忌

**禁止把后人编注、现代译文或二手转述标成原始史料；出处、年代或版本无法核验的材料只能标“待核”，不得补造档号、页码或引文。**

## ④ 经管实证型

适用于经济学、管理学、社会学定量研究及政策评估。核心证据是研究设计与识别假设、系数大小和经济意义、以及结果在合理规格变化下是否稳定。

### 招牌页 1：模型设定与识别策略页

- **构图配方**：左栏约 34% 放研究设计卡，逐项写分析单位、时间范围、样本形成、核心解释变量、被解释变量；中部约 40% 放可编辑文本排版的模型公式，公式下接变量定义小表；右栏约 26% 放识别 callout，写外生变化来源、固定效应、聚类层级和关键假设。
- **公式规范**：下标用小字下沉，系数与变量一一对应；公式中出现的每个符号必须在变量定义表中出现。双重差分、工具变量、断点等设计要在公式旁用一句话说明处理组、对照组和识别变异来源。
- **样本账**：页面底部加一条样本形成带：初始观测 → 各项剔除 → 最终样本，逐步写观测数；公司—年度、个人—波次等层级不得混写。缩尾、价格平减、汇率或行业分类口径写在样本带或表注中。

### 招牌页 2：回归结果表页

- **构图配方**：用原生表格，列为模型 (1)–(4)，按“基础规格 → 加控制变量 → 加固定效应 → 首选规格”递进；行首只完整展示核心解释变量，控制变量压缩为“控制变量：是/否”与固定效应行。首选规格列用极浅蓝底，核心系数旁只许一个橙色小点标示。
- **数字排版**：系数写在单元格第一行，标准误用括号写在正下方，显著性星号紧随系数；不同模型列宽一致，小数位数全表统一。表底依次放观测数、聚类数、$R^2$ 或调整 $R^2$、被解释变量均值。
- **表注自含**：表注必须写标准误类型与聚类层级、星号阈值、固定效应、样本限制和变量变换（如对数、标准化）；禁止给每个显著系数上色，也不得删去不显著的首选规格结果。

### 招牌页 3：稳健性与动态效应页

- **构图配方**：中部用系数稳定性图：每行一个预先有理由的替代规格，横向画点估计与 95% CI，设零线，基准规格用橙点、其余用蓝系；右栏同步写规格变化和样本量。替代口径、替代样本、替代聚类、安慰剂和排除特殊时期各占一行，不按显著性排序。
- **动态效应变体**：事件研究设计改画事件时间系数图，处理前各期与置信区间逐点呈现，处理时点用竖虚线；图注明确基期。若处理前趋势不通过，标题和结论必须直接写出，不得只展示处理后系数。
- **结论带**：写结果在哪些变化下保持、哪一规格明显减弱以及这对解释边界意味着什么；“不显著”写置信区间覆盖的效应范围，不写成“证明无效应”。

### 通用页适配要点

- 提纲按“研究问题 → 制度背景与机制 → 数据和识别 → 基准结果 → 机制/异质性 → 稳健性 → 结论”组织；背景页加一张简洁机制链图，并把可检验假设标为 H1、H2，后文结果逐项回应。
- 所有表格的注释必须脱离正文也能读懂；数据页脚标数据来源、年份范围、数据库版本或提取日期。异质性分析须报告交互项或组间差异检验，不能并列两个亚组系数后凭显著性差异下结论。
- 结论页同时翻译统计意义与经济意义：把核心系数换算为原单位、相对于均值的百分比或标准差变化；政策含义不得超出识别设计能支持的人群、时期和制度环境。

### 本类特有禁忌

**禁止按显著性挑选并只展示有利规格，或把回归相关直接写成因果效应；与主结论不一致的预设稳健性结果也必须同页呈现并解释。**

## 交付前学科口径检查

1. 页型是否与证据生成方式匹配，标题是否已写成可被本页证据支持的结论。
2. 图注、表注是否自含对象、口径、来源和关键限制，编号是否全册连续。
3. 所有数字是否能回溯到同一数据划分、分析集、版本源或模型规格；跨页引用是否使用同一名称和单位。
4. 主类特有禁忌是否逐项排查；跨类借用页型时，是否保留原类的标注义务。
