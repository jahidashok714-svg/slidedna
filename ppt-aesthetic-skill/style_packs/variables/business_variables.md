# 变量扩展 · 商务包行业扩展（business variables）

本文件是 `../business.md`（商务风格包）的行业变量层：一本 deck 选定分支（稳重 / 活力 / 路演）之后，再按客户行业套本文件对应一节——换指标词、换招牌页构图、守行业语气。色板、字体梯度、图表语法、组件与禁忌一律沿用主包，本文件不新造任何视觉元素；一本 deck 只用一个行业节，不跨行业拼词。

通用规则（六个行业都适用）：

- 指标词库里的词就是页面标题、指标卡与图表系列名的用词来源，不临时自创近义词混用；每个指标首次出现时在页脚或图注给一句口径（统计范围 + 时间口径）。
- 招牌页是主包通用页型（数据页 / 表格页 / 大数字页 / 风险页）的行业变体，构图骨架不变，只换数据组织方式。
- 行业数字必须全册自洽：分项加总 = 总数、占比合计 100%、同一指标跨页同值；推导值在构建报告里注明来源（参照 SaaS 节即样板的做法）。

## 1. 软件 / SaaS（已验证 · 参照样板 trial2 v4「屿星云科」）

### 指标词库

| 指标 | 口径一句话 |
|---|---|
| 营业收入（分业务线） | 订阅 / 私有化许可 / 实施与服务三线分列，分项加总 = 总营收 |
| 订阅收入占比 | 订阅收入 ÷ 总营收；衡量经常性收入基本盘 |
| 净收入留存率 NRR | 存量客户本期收入（含扩容、扣流失）÷ 上年同期收入，同客户口径 |
| 企业客户收入占比 | 年合同额 ≥50 万元客户收入 ÷ 总营收（门槛须在页脚注明） |
| 综合毛利率 / 订阅毛利率 | 毛利 ÷ 收入；订阅毛利率单列，与综合毛利率分开讲 |
| 新增签约客户 / 累计付费客户 | 当期新签家数与期末存量家数，两个数不混写 |
| 私有化交付周期 | 合同生效至验收通过的平均自然日，对照内部目标（如 55 天） |
| 获客成本 CAC | 当期销售市场费用 ÷ 新增签约客户数 |
| 经营活动现金流净额 | 现金流量表口径，注明连续为正 / 转正的季度数 |
| 计划完成率 | 实际 ÷ 季度（年度）计划目标，目标值须同时给出 |

### 招牌页变体

- **业务线拆解页**（数据页变体）：原生分组柱状图，三系列固定色序（主色黄 = 第一业务线、炭灰 = 第二、浅灰 = 第三），数据直标；最高单季峰值上方加标注气泡（值 + 业务线名）；右侧深色洞察栏放三条结构变化（占比 / 增速 / 绝对额），每条配一个极简形状图标。标题写结论（如「订阅主导，私有化提速」），不写「各业务线收入情况」。
- **区域与客户结构页**（表格页变体）：原生表格，列 = 区域 / 营收 / 占比 / 新增客户 / 客单价（= 营收 ÷ 新增客户，逐行可复算）；占比列行下沿加单元格内数据条，条宽与百分比严格成正比；标题点名的区域（如增速最高行）整行描边高亮，其数据条用深一号黄。

### 语气与禁忌

- 忌把实施与服务收入包装成经常性收入；NRR、续约类指标必须给同客户口径，不用全量收入增速冒充留存。

### 分支建议

- 默认**稳重系**：汇报对象是客户决策层与内部经营会，炭灰 + 芥末黄的可信感优先；仅融资路演且听众为投资机构时换路演系。

## 2. 制造业

### 指标词库

| 指标 | 口径一句话 |
|---|---|
| 产能利用率 | 实际产量 ÷ 设计产能（同产线口径），按产线 / 工厂分列 |
| 一次良率（直通率） | 一次检验合格数 ÷ 投产数，不含返修后合格 |
| 不良率 / 缺陷 Top 项 | 不良品 ÷ 总产出；缺陷按柏拉图排序取前 3–5 项 |
| 设备综合效率 OEE | 时间开动率 × 性能开动率 × 合格品率，三项可拆 |
| 在手订单 | 期末已签未交付订单金额，注明覆盖月数（÷ 月均交付额） |
| 订单准时交付率 OTD | 按承诺日期准时交付订单数 ÷ 应交付订单数 |
| 平均交付周期 | 下单至交付的平均自然日，与 OTD 配套出现 |
| 单位制造成本 | 制造成本 ÷ 合格品产量，与上期同口径对比 |
| 库存周转天数 | 平均库存 ÷ 日均销售成本；原材料 / 在制品 / 成品分列 |
| 安全事故与停线时长 | 事故起数 + 非计划停线小时数，无事故也要明示为 0 |

### 招牌页变体

- **产线与良率页**（数据页变体）：左 = 各产线产能利用率条形图（主色单色，目标线 85% 用炭灰虚线 + 标签直贴）；右 = 良率季度折线（形状化折线或原生折线套包色序）+ 缺陷 Top3 横条小图。标题写结论（如「二线良率拖累整体直通率 1.2 个点」）。一页只讲一对量—效关系，不把 OEE 三项全塞进同页。
- **订单与交付页**（大数字页 + 表格页组合）：上半在手订单大数字（深色满版页额度内使用）+ 覆盖月数一行结论；下半交付表：客户 / 项目 / 承诺日期 / 状态，延期行用深黄描边标出（不用红），OTD 放在表头结论句里。

### 语气与禁忌

- 忌只谈订单额不谈交付与良率：凡讲订单增长的 deck，交付周期与良率必须同册出现，顺序可在后、不得缺席。

### 分支建议

- 默认**稳重系**：制造业汇报对象多为客户验厂、集团经营会与银行，可信与精确优先；活力系仅用于对经销商的年度订货会类场合。

## 3. 零售 / 电商

### 指标词库

| 指标 | 口径一句话 |
|---|---|
| GMV / 实付金额 | 下单口径与支付口径分开写，注明是否含退款冲减 |
| 同店增长率 | 开业满 12 个月门店的可比口径销售额同比，剔除新店与闭店 |
| 坪效 | 门店销售额 ÷ 营业面积（元/㎡/月），按店型分列 |
| 转化率 | 支付买家数 ÷ 访客数（电商）或成交单数 ÷ 进店人数（门店） |
| 客单价 | 实付金额 ÷ 支付订单数 |
| 连带率 | 销售件数 ÷ 订单数，服装 / 商超类必备 |
| 复购率 | 统计期内购买 ≥2 次客户数 ÷ 总购买客户数，注明窗口期 |
| 售罄率 / 库存周转 | 售出件数 ÷ 进货件数（当季商品）；周转按平均库存口径 |
| 退货率 | 退货件数 ÷ 签收件数，服饰类必须单列 |
| 渠道 ROI | 渠道归因 GMV ÷ 渠道投放费用，归因窗口须注明（如 7 天） |

### 招牌页变体

- **同店与坪效页**（数据页变体）：门店按坪效分三档（头部 / 腰部 / 尾部）做分组条形，同店增长率用对位说明栏逐档给数；尾部门店不藏进平均数，单独一行给关店 / 改造计划。标题写结论（如「尾部 12 店拖累同店增速 2.3 个点」）。
- **大促复盘页**（漏斗 + 峰值标注）：访客 → 加购 → 下单 → 支付四层漏斗（形状自绘，层宽 ∝ 人数，层间转化率直贴），右侧诊断栏点名最短板一层；若配趋势图，大促日峰值上方加标注气泡，口径同 SaaS 节峰值标注做法。

### 语气与禁忌

- 忌只报 GMV 不报退货率与毛利：GMV 出现的页，同册必须能找到退货率和毛利口径，禁止用下单口径冒充实付。

### 分支建议

- 默认**活力系**：消费品牌与电商汇报需要品类色彩，五色固定序列正好对应品类轮转（封面 → 表头 → 环图同序）；集团层面的年度经营汇报换稳重系。

## 4. 金融服务

### 指标词库

| 指标 | 口径一句话 |
|---|---|
| 资产规模 / 管理规模 AUM | 期末时点数，注明表内 / 表外口径 |
| 营业收入与结构 | 利息净收入 / 手续费及佣金净收入 / 投资收益分列，占比合计 100% |
| 净息差 NIM | 利息净收入 ÷ 平均生息资产，年化口径 |
| 不良率 | 不良余额 ÷ 总余额（贷款或资产口径须写明），与上年末比 |
| 拨备覆盖率 | 贷款损失准备 ÷ 不良贷款余额 |
| 资本充足率 | 资本 ÷ 风险加权资产，集团与核心一级分列 |
| 成本收入比 | 业务及管理费 ÷ 营业收入 |
| 净资产收益率 ROE | 归母净利润 ÷ 平均净资产，年化 |
| 中间业务收入占比 | 手续费及佣金净收入 ÷ 营业收入 |
| 客户数 / 户均 AUM | 期末零售客户数与户均管理资产，注明活跃口径 |

### 招牌页变体

- **规模与质量页**（大数字页 + 对照条）：左规模大数字（资产规模，含同比一行）；右质量对照区：不良率、拨备覆盖率、资本充足率三条横向标尺条，监管参考值位置用芥末黄刻度线 + 小字标注（如「不良率 1.6% 参考线」），实绩条用炭灰——全程只用包内色，不引入红绿。标题结论先讲质量再讲规模。
- **收入结构页**（数据页变体）：环图横排（≤5 个扇区，按包色序），中心放营业收入总额；对位说明栏逐项给占比与同比变化，占比合计必须 100%，差值归入「其他」项不抹平。

### 语气与禁忌

- 忌娱乐化与承诺式表达：不用网感词、不用感叹号堆叠，禁用「稳赚」「保收益」类措辞；不良率等风险指标必须进正文页，不得只放在附注或脚注里。

### 分支建议

- 默认**稳重系**且不轻易换：持牌机构汇报的合规感来自克制；路演系仅限金融科技公司面向投资人的融资路演，传统机构年报 / 监管汇报禁用。

## 5. 医疗健康

### 指标词库

| 指标 | 口径一句话 |
|---|---|
| 门急诊量 / 出院量 | 统计期内人次，与上年同期同口径（机构运营类） |
| 床位使用率 / 平均住院日 | 实际占用床日 ÷ 开放床日；出院者平均住院天数 |
| 手术量与四级手术占比 | 手术台次及高难度等级占比，注明分级标准版本 |
| 药耗占比 | 药品 + 耗材收入 ÷ 医疗收入，控费口径必备 |
| 医保结算占比 | 医保基金结算金额 ÷ 医疗总费用，注明统筹区口径 |
| 患者满意度 | 第三方或院内问卷得分，注明样本量与回收率 |
| 装机量 / 单机产出 | 设备累计装机台数与单台年均检测 / 治疗人次（器械类） |
| 注册证与准入进度 | 已取证 / 在审 / 临床阶段产品数，阶段口径写明（器械 / 药企类） |
| 集采中标与份额 | 中标品种数与约定采购量完成率（器械 / 药企类） |
| 复诊率 / 随访完成率 | 规定窗口内完成复诊或随访患者占比 |

### 招牌页变体

- **量—效运营页**（数据页变体）：左量（门急诊量 / 装机量分组柱），右效（床位使用率 / 单机产出条形），中间用一条结论带收束「量增效不减」或点名背离项；量与效必须同页对照，禁止只放量的单边页。
- **质量与合规页**（表格页变体）：清单式原生表格：指标 / 目标值 / 实际值 / 状态四列，状态列只用包内表达（达标 = 炭灰字，未达 = 深黄描边行），药耗占比、满意度等管控指标逐行列示，不合格项同行给整改节点。

### 语气与禁忌

- 忌夸大疗效与超范围表述：不写未获批适应症、不做治愈率类宣传化承诺；一切运营数据注明统计期与机构范围，多院区合并口径须说明。

### 分支建议

- 默认**稳重系**：医疗汇报对象含主管部门、院方与支付方，严谨优先；活力系仅用于面向消费者的健康品牌发布类场合，且疗效表述禁忌不变。

## 6. 工程 / 地产

### 指标词库

| 指标 | 口径一句话 |
|---|---|
| 新签合同额 | 当期签订合同总金额，区分施工 / 设计 / 采购口径（工程类） |
| 在建项目产值 | 当期完成施工产值，按项目或区域加总 = 总产值 |
| 回款率 | 当期实际回款 ÷ 当期应回款（按合同节点），与新签额配套出现 |
| 项目毛利率 | （项目收入 − 项目成本）÷ 项目收入，完工百分比法口径注明 |
| 节点达成率 | 按期完成里程碑节点数 ÷ 应完成节点数，延期节点逐个列名 |
| 安全事故 / 零事故天数 | 事故起数与连续无事故天数，无事故明示为 0 起 |
| 土地储备与货值 | 待开发土地建筑面积与预估货值（地产类） |
| 签约销售额与去化率 | 签约口径金额；去化 = 当期售出 ÷ 当期推出房源（地产类） |
| 已售未结转金额 | 已签约未确认收入金额，预告下期收入可见度（地产类） |
| 竣工交付量 | 当期竣工面积 / 交付套数，与承诺交付计划对照 |

### 招牌页变体

- **项目组合页**（表格页变体）：原生表格按区域或项目分级（重点 / 常规 / 尾部）排列，列 = 项目 / 产值或货值 / 节点状态 / 回款率；延期与低回款项目描边标出并在表下用一行给处置动作。标题写结论（如「三项目延期吃掉 Q4 产值 8%」）。
- **节点与回款页**（时间轴 + 进度条）：上方月度泳道里程碑（菱形节点，做法同 SaaS 样板路线图页），下方各项目回款进度条（条长 ∝ 回款率，应回款额直贴条尾）；节点轴与进度条共用同一项目编号，两处状态必须一致。

### 语气与禁忌

- 忌只报签约不报回款与交付：新签合同额出现的 deck，回款率与节点达成率必须同册；安全指标必须进正文页，零事故也要明示，不得省略。

### 分支建议

- 默认**稳重系**：工程与地产汇报对象多为业主、政府平台与金融机构，履约可信度优先；路演系仅用于地产新品发布会与工程企业融资路演，不用于履约类汇报。

## 使用顺序（一本 deck 的变量装配）

1. 按客户场景在主包三分支中定系（无行业建议冲突时用本文件该行业的默认分支）。
2. 从该行业指标词库取词搭指标卡、图表系列名与标题，首次出现处补口径注脚。
3. 招牌页按本文件变体构图替换通用页型的同位页，其余页型照主包配方。
4. 按该行业禁忌逐页自查一遍（重点：被忌讳的缺席项是否在册、风险类指标是否进了正文页）。
5. 数字自洽核对（加总、占比、跨页同值）后交付，推导口径写入构建报告。
