# 数据包变量扩展 · 分析对象扩展（data_variables）

配合 `style_packs/data.md` 使用：风格包定视觉体系（四套色方案、一页一图、标签直贴、表格原生细线），本文件定**分析对象**的图型组合与口径纪律。接活先定对象 → 按本文件选图型与口径 → 回 data.md 取色与页型，不得新造视觉体系、不得跨对象借口径。

通用纪律（六类对象共用，沿自样板沉淀）：一页一图、标签直贴不用图例框；图表标题必须是结论句而非描述句；所有分项加总、占比合计、逐层乘率在交付前逐项复算（报告附口径核对表）；数据页页脚标数据来源与统计周期；虚构/示例数据必须就地标注。图型优先用包的形状化数据图语言（条形、漏斗、甘特、环图、滑杆），须可编辑数据时改用原生图表并套所选方案色序、关默认样式。

## 1. 电商运营（已验证 · 样板沉淀）

参照实现：《云汀商城 2026 年度运营数据分析报告》（科技蓝，12 页）——本节即从该样板提炼，后续电商单子以它为结构母本换数据重建。

**核心图型组合**
- 月度趋势折线（标记点 + 数据直贴）：回答"全年走势长什么样、峰谷在哪"；大促/活动节点用标注芯片钉在对应月份上，标题直接写双峰贡献占比。
- 形状漏斗（访客 → 加购 → 下单 → 支付，层间转化率独立标注列）：回答"流失发生在哪一层"；整体转化率与最短板层必须同页出现。
- 品类条形图（条宽严格 ∝ 金额，增速第一行高亮）：回答"基本盘是谁、增量是谁"；右侧附同比列，不另开一页。
- 分层分组柱（人数占比 vs 金额占比双系列）：回答"人多不等于钱多"——会员/用户分层的结构错位一张图说清。
- 渠道 ROI 表（原生表格 + 占比数据条 + 逐行 ROI）：回答"钱花在哪最值"；合计行给综合 ROI 与费用率。

**口径红线**
- ROI 归因口径必须在框架页先钉死：归因窗口（如点击后 7 天）、末次点击还是首次点击、GMV 按支付口径还是下单口径——三者任一不同，渠道间 ROI 不可比；合计行必须与分项同口径加总。
- 漏斗各层人数与层间转化率必须逐层可乘回去；出现"支付 ÷ 下单 ≈ 35.0%"这类四舍五入要在图注注明，禁止为了凑整改原始人数。

**推荐色方案**：科技蓝。理由：电商汇报节奏快、页面多，双蓝同色系足以区分主次（强调给亮青蓝、次级给深蓝），不必动用六色；四角斜切双色块作全册识别符，换商家时只换识别符内的品牌名。

**诊断页版式**：一条问题一带横排——左问题标题、中三枚证据数字、右影响测算栏收尾，问题与后页策略一一编号对应。

## 2. 金融风控

适用：信贷/支付/消费金融的风险月报、审批与贷后分析、反欺诈专题。气质要求：审慎、精确，任何"好看"让位于口径正确。

**核心图型组合**
- 风险指标趋势折线（逾期率/不良率/通过率双轴或双联图）：回答"风险在变好还是变坏"，拐点处标注政策或规则上线节点。
- 账龄/迁徙矩阵（原生表格热力式填色，进包色序的同色深浅）：回答"资产在风险等级间往哪迁"——行是上期等级、列是本期等级，对角线占比是稳定性本身。
- 评分分布直方（形状条形，按评分段）：回答"客群质量结构长什么样"，拒绝线（cutoff）用竖线钉在图上，通过/拒绝两侧分色。
- 漏斗（申请 → 审批 → 放款 → 首逾期）：回答"量缩在哪、坏账出在哪"，与电商漏斗同形但每层必须带金额与件数双口径中的一件数。
- 欺诈/异常案件条形（渠道或团伙维度）：回答"攻击集中在哪"，只排前 5–8 类，其余合并"其他"并注占比。

**口径红线**
- 逾期口径先于一切：DPD30+/DPD90+、账龄口径（M1/M2…）还是 vintage 口径必须在封面或框架页声明；不同账龄的队列不可直接比逾期率（未成熟队列会系统性显得更安全）。
- 分母纪律：通过率分母是申请件数还是进件件数、逾期率分母是应还金额还是放款金额，换分母必须在图注标红说明，禁止同页混用两个分母不注明。

**推荐色方案**：深蓝正式。理由：风控汇报对象是风险委员会与监管口径，深海军蓝的克制与单色深浅正合"坏消息不用亮色报"的行业气质；多色仅限迁徙矩阵内部且 ≤5 色。

**诊断页版式**：左图右表对照——左放出险指标的趋势小图，右用原生表格逐行列"指标/当前值/阈值/状态"，状态只用同色深浅与文字，不用红绿灯三色。

## 3. 用户增长 / 留存

适用：互联网产品的增长复盘、留存专题、渠道拉新质量分析。核心叙事是"来的人对不对、留没留得住"。

**核心图型组合**
- 队列留存曲线（多条折线，每条一个注册月队列，横轴为注册后周/月数）：回答"哪批用户质量变了"，标题写第 N 期留存的队列间差值，不写平均留存。
- 留存矩阵（原生表格，同色深浅填格）：回答"留存衰减的形状"——行是队列、列是期数，找对角线与列向的异常格，是曲线页的表格孪生页，二选一做主图、另一个进附录。
- 增长拆解恒等式图（形状化加减条：期初 + 新增 + 回流 − 流失 = 期末）：回答"增长到底由哪块驱动"，每块带绝对值与占比，禁止只报净增。
- 渠道质量双条形（拉新量 vs 次留/7 留，同渠道两条对照）：回答"谁在买量、谁在买人"，量大质差的渠道必须同页现形。
- 关键行为漏斗（注册 → 激活事件 → 核心动作 → 留存达标）：回答"激活卡在哪一步"，激活事件的定义写进图注。

**口径红线**
- 留存分母只能是同期群（cohort）的期初人数：禁止用"本月活跃中上月也在的人 ÷ 本月活跃"冒充留存率；留存口径（次日/7 日/30 日、自然日还是滚动 24 小时、按注册还是按首次激活起算）必须在框架页钉死，全册不换。
- 回流用户不计入新增：新增、回流、流失三者互斥且合计可对到期末活跃，渠道 ROI 页若按新增付费，归因窗口与回流判定要与电商对象对齐声明。

**推荐色方案**：紫单色咨询。理由：增长汇报多为内部策略讨论，单色深浅正好编码"队列新旧/程度强弱"这类单调序关系，不需要多色相；高密度正文（10 pt）也容得下留存矩阵的细格。

**诊断页版式**：上方一条全宽留存曲线作证据带，下方左右两栏——左"掉队队列"（哪批、掉多少），右"已验证有效的动作"（做过什么、拉回几个点），不写无数据支撑的猜测栏。

## 4. 财务经营分析

适用：经营分析会材料、财务月报/季报、预算执行与差异分析。数字将进决策，口径比版式重要一个量级。

**核心图型组合**
- 瀑布图（形状拼图：期初值 → 各项增减浮动柱 → 合计值）：回答"利润/收入从 A 到 B 的桥是怎么搭的"，增减项按贡献绝对值排序，合计柱用深色钉住。
- 实际 vs 预算分组柱（或子弹式滑杆）：回答"哪项偏了、偏多少"，差异率直贴在柱端，超预算与未达标用同色深浅区分不用红绿。
- 同比/环比双联趋势（柱表当期值、线表同比增速）：回答"增长是真增长还是低基数"，基期异常月份必须加注。
- 费用结构环图或堆积柱（占比直贴）：回答"钱的结构变了没"，只画前 5 大项，环图线宽约直径 8%（包规范）。
- 杜邦/驱动树（细线树状分行）：回答"ROE/毛利率由哪几个因子推动"，每个节点带当期值与同比变化，变化方向用文字（↑↓）不用颜色暗示。

**口径红线**
- 同比与环比的基期必须可复核：同比基期遇一次性事项（并表、补贴、疫情式异常）要在图注披露并给"剔除后口径"的对照数；环比禁止拿季节性月份直接连比而不注季节性。
- 预算差异口径统一：差异率分母永远用预算数（不是实际数）；收入确认口径（总额法/净额法、含税/不含税）换口径的年份，历史数据要么重述要么断线，禁止一条折线跨两种口径。

**推荐色方案**：深蓝正式。理由：财务材料进的是经营会与董事会，深色正式方案的窄体字与大数字页（96 pt 单数字居中）最接近财务演示的既有语感；表格走深底细白线 + 半透明斑马行。

**诊断页版式**：差异归因一页一座桥——上方瀑布图给全貌，下方原生表格逐项列"项目/差异额/差异率/原因一句话"，表格行序与瀑布柱序严格一致。

## 5. 人力资源分析

适用：人力盘点、招聘效能、组织与人效分析、离职专题。涉及人的数据，先讲清统计范围再讲结论。

**核心图型组合**
- 组织结构条形组（按层级/序列/司龄段的人数分布条形）：回答"人都在哪一层、哪一段"，结构异常（某层级膨胀、司龄断层）在标题点名。
- 漏斗（简历投递 → 筛选 → 面试 → offer → 入职 → 转正）：回答"招聘漏在哪一环"，每层带转化率与平均停留天数双标注。
- 人效趋势（人均产出/人均成本双线或柱线组合）：回答"扩招有没有换来产出"，必须与同期业务量指标同页，禁止单独报人效不报业务背景。
- 离职率分段条形（按司龄段或绩效段）：回答"走的是谁"——主动离职与被动离职分段堆积，关键人才段单独高亮一行。
- 编制甘特（胶囊圆角条，包规范）：回答"编制与招聘节奏对不对得上"，计划 vs 实际两行对照。

**口径红线**
- 人数口径必须在框架页声明：在职/在岗/含外包与实习生的哪一种，期末时点数还是期间平均数；离职率分母用期间平均人数（不是期末人数），且主动/被动、试用期离职是否计入要注明——换口径的历史数据不可直接连线。
- 人效的分母与分子要同期间、同范围：人均营收用平均人数不用期末人数；涉及薪酬的页只给指数或区间，不出现可反推到个人的粒度（合规与隐私红线，图注注明脱敏方式）。

**推荐色方案**：白底六色。理由：HR 汇报对象多为业务负责人联席会，白底汇报感强、阅读门槛低；六色序正好给层级/序列/司龄段这类多分类变量固定编码，全册左缘六色小方块作图例列保持一致。

**诊断页版式**：左"结构图"右"名单式结论"——左放出问题的分布条形（膨胀层级/断层司龄段高亮），右逐条列"现象/影响的团队范围/建议动作与时间"，不做大段文字墙。

## 6. 供应链 / 物流

适用：供应链月度运营、库存健康、物流时效与成本分析。叙事主线是"货在哪、堵在哪、钱压在哪"。

**核心图型组合**
- 库存周转与库存金额双联图（柱表库存金额、线表周转天数/周转率）：回答"压货是在涨还是在消"，呆滞库存占比在标题或峰值标注中点名。
- 库龄分布堆积条（0–30/31–90/91–180/180 天+ 四段）：回答"库存老不老"，最老一段固定用方案内最深色，段界定义写进图注。
- 时效趋势折线（下单→出库→签收分段时长或准时交付率 OTD）：回答"慢在哪一段"，分段时长用堆积柱的孪生页对照，异常月份标注大促/天气/封仓等事件。
- 供应商/承运商评分原生表格（交付、质量、成本三维 + 数据条）：回答"谁靠谱、谁该淘汰"，合计/均值行与分项同口径，评分权重在表注披露。
- 成本结构环图或瀑布（运费/仓储/包材/逆向四分）：回答"物流的钱花在哪、逆向吃掉多少"，逆向（退货）成本必须单列不许摊进正向运费。

**口径红线**
- 周转率口径二选一钉死：周转率 = 销售成本 ÷ 平均库存（不是期末库存），周转天数 = 期间天数 ÷ 周转率；用销售额代替销售成本算周转会系统性高估，必须注明。库存金额按成本价还是零售价同册统一。
- 时效的起止点定义不可含糊：OTD 的"准时"以承诺时效还是以行业标准计、签收时间以物流回传还是客户确认计，换承运商导致口径变化的月份要在图上断线或加注，禁止无声拼接。

**推荐色方案**：科技蓝。理由：供应链汇报常与运营、数据团队同场，科技蓝的墨线 + 单蓝点睛适合长时间看图不累眼；时效与库龄这类"程度"变量用双蓝深浅编码足够，不必引入多色相。

**诊断页版式**：横向一条"链路带"——按入库→在库→出库→在途→签收五段排开，每段一枚关键数字与一句状态，堵点所在段整段高亮，下方再接一段归因文字，链路顺序永不打乱。
