# 变量扩展 · 正式汇报（formal）— 单位类型扩展

本文件是 formal 包的变量层：在 formal.md 的两分支（党政红 / 政务蓝）与页型配方之上，只调整**称谓、落款、章节结构与语气边界**，不新造视觉体系。色板、字号梯度、徽章（红：缎带书签；蓝：正圆 / 菱形）、缎带条（一册一条）、分隔线、内容卡语法一律以 formal.md 为准。

## 使用规则

1. 接活先定单位类型（政府机关 / 国有企业 / 事业单位 / 群团与行业协会），再查本文件对应节，最后按 formal.md 选分支、排页型。
2. 同一册内单位类型只认一个主类型；混合型单位（如高校附属医院）以汇报对象（向谁汇报）归类，不混两类的称谓与结构。
3. **红线（与 formal.md 禁忌并行）**：任何单位类型下，都不得使用、绘制或仿制党徽、国徽、印章等官方徽标图案；formal.md 红分支封面 / 章节页的"顶部徽标"位置，仅当客户从其官方材料提供合规徽标图时才放实物图，未提供则该位置留空或改放单位名文字，绝不用自制图形替代。红分支的其他象征性素材（主题照片、缎带压级）同样优先取客户官方材料。
4. 结尾页一律"同封面底图 / 底色 + 一句致谢居中 + 右下落款"（formal.md 结尾页配方），落款的单位全称与日期写法按下文各节执行。

## 参照样例

政务蓝分支的已沉淀做法见样板《云汀市数据资源管理局 2026 年度工作汇报》（市级政府直属局，见仓库 examples 正式样板）：封面"主色缎带（关键词四则）→ 单位名 → 标题 → 副题"的文字层级、总览页四张大数字卡 + 深藏青"全年工作主线"带、计划页四季度菱形节点轴与编号任务逐项对应、附页"关键数据一览"汇总表收口径——均属"政府机关"一节的默认实现，可直接比照迁移到其他机关单位。

## 一、政府机关（委办局、乡镇街道、开发区管委会等）

### ① 称谓与落款惯例
- **自称**：正文统一用"本局 / 本委 / 本办 / 本单位"或全称简称（如"市数据局"），不用"我局"（口语）与"我们"；汇报人身份在封面副题或总览页首段交代一次（"XX局 2026 年度工作汇报"），此后不再重复自报。
- **排序**：封面层级固定为"缎带关键词 → 单位全称 → 汇报名 → 副题（工作范围一句）"；领导与上级单位只在正文致谢段或结尾前提及，机关单位封面不列个人姓名。
- **结尾页格式**：致谢一句居中（"汇报完毕，谢谢大家"一类）；右下落款两行——单位全称 + 日期，日期用汉字数字写法（如"二〇二七年一月"），与样板一致；落款不加职务、不加个人签名式字体。

### ② 章节结构惯例
- 篇章顺序走公文汇报的固定链：**年度工作总览（成效先行）→ 重点工作分述（一、二、三编号推进）→ 专题研讨 / 工作交流（如有）→ 存在问题与不足 → 下一年度工作计划 → 保障措施 → 附：关键数据一览**。
- 小标题句式：总览与重点工作用"名词短语 + 成效指向"（如"数据汇聚：建成全市统一汇聚通道"），问题部分用克制的判断句（"数据质量仍有差距"），计划部分用"动词 + 对象 + 量化目标"（"冲刺年度汇聚总量 16 亿条"）；一册内句式长度大致齐整，不写口号式排比。
- 问题部分必须独立成章且排在计划之前——机关汇报的审查习惯是"先认问题、再谈打算"，把问题并入成效页会被视为回避。

### ③ 分支选择建议
- **首选政务蓝**：委办局日常工作汇报、专项汇报、年终总结的默认分支，庄重但不涉党务象征，样板已验证全套页型可落地。
- **党政红仅用于**：党建述职、党组（党委）专题汇报、主题教育总结等汇报对象与主题本身属党务的场合，且徽标与主题照片须由单位提供官方材料（见使用规则 3）；一般行政业务汇报不上红分支，避免规格错位。

### ④ 特有禁忌
- 忌在正文里写决策性表态（"决定""要求各单位必须"）——汇报稿是陈述体不是发文体；涉及上级部署只写"按照市委、市政府部署"式的承接表述，不替上级发声。

## 二、国有企业（央企 / 地方国企、城投交投类平台公司）

### ① 称谓与落款惯例
- **自称**：用"公司 / 集团"或品牌简称（如"云汀城投"），经营口径可出现"我们"但正式总结页仍回"公司"；可在封面副题下加一行经营定位语（如"城市基础设施投建运一体化服务商"），这是国企独有、机关没有的位置。
- **排序**：封面层级为"单位全称 → 汇报名 → 年度经营关键词缎带"；如汇报对象是国资委或集团上级，副题注明报送关系（"向市国资委汇报"），不写个人领导致谢名单于封面。
- **结尾页格式**：致谢居中 + 右下落款"单位全称 + 日期"，日期用阿拉伯数字写法（"2027 年 1 月"）即可，不必学机关的汉字数字；可在落款上方加一行下年度经营目标句（一句封顶）。

### ② 章节结构惯例
- 篇章顺序走"经营叙事"链：**年度经营总览（营收 / 利润 / 资产等核心指标先行）→ 主业板块分述（按业务板块而非处室划分）→ 重大项目与投资进展 → 改革与风控（国企改革、债务与合规单列）→ 存在问题 → 下一年度经营计划与目标 → 保障措施**。
- 小标题句式：板块页用"板块名 + 一句经营结论"（如"交通建设板块：营收占比过半，毛利率承压"），指标必须进标题或紧随标题的大数字卡；计划部分标题直接带目标数（"2027 年营收目标 XX 亿元"）。
- 数据页优先：国企汇报的数据页密度可高于机关（多图多表），但仍守 formal 蓝分支的单色数据语法（原生表格 / 形状化图表按 formal.md 数据页配方）。

### ③ 分支选择建议
- **首选政务蓝的青蓝档（`#4F91A0`）**：formal.md 已注明"青蓝偏企业汇报"——国企既要庄重又不是机关，青蓝正好落在中间；标准蓝（`#0070C0`）留给向监管 / 国资口径极正式的报送场合。
- **党政红仅用于**：企业党委会 / 党建工作汇报、党组织书记述职；经营工作汇报即使由党委书记主讲也不上红分支，主题决定分支，不由汇报人身份决定。

### ④ 特有禁忌
- 忌把机关公文语气用过头：通篇"高度重视、狠抓落实、扎实推进"而无经营数字，会被上级与同行判定为"以党建材料冒充经营汇报"；每一章至少落一个可核对的经营指标，空话段落整段删。

## 三、事业单位（高校、医院、科研院所、文化场馆等）

### ① 称谓与落款惯例
- **自称**：用"本校 / 本院 / 本所"或单位简称；学术与医疗单位可在封面副题注明学科 / 专科定位（高校："双一流建设高校 · XX 学科"；医院："三级甲等综合医院 · XX 专科"），一行为限。
- **排序**：高校封面层级为"单位全称 → 汇报名 → 学年 / 年度字样"；医院为"单位全称 → 汇报名 → 周期字样（年度 / 季度运营）"。涉及校长 / 院长致辞页时，个人只出现在该页，不进封面层级。
- **结尾页格式**：致谢居中；右下落款"单位全称 + 日期"，高校偏汉字数字日期（"二〇二七年一月"）显学术气，医院用阿拉伯数字日期（"2027 年 1 月"）与病历文书习惯一致；两者都不加个人落款。

### ② 章节结构惯例
- **高校**：总览（办学核心指标）→ 人才培养 → 科学研究 → 学科建设 → 师资队伍 → 社会服务与合作 → 问题 → 下一学年计划。指标口径用生均、占比、增量等教育统计口径，忌用营收式指标当主指标。
- **医院**：总览（医疗业务量与质量指标）→ 医疗质量与安全（单列且靠前）→ 学科与人才 → 运营效率 → 患者服务 → 问题 → 下一年度计划。质量安全章的位置不可被运营数据章挤到后面。
- 小标题句式：用"领域 + 进展判断"（如"科学研究：高水平成果数量与质量同步提升"），成果页按"成果名 + 级别 / 出处"列示（如"国家自然科学奖二等奖""SCI 一区论文 XX 篇"），不堆形容词。

### ③ 分支选择建议
- **首选政务蓝（标准蓝 `#0070C0`）**：事业单位的报送对象多为上级主管部门，标准蓝与机关口径衔接最顺；高校在校庆、党代会等校内仪式场合可用红分支，但须用学校官方提供的校徽 / 主题图（红线规则同前，校徽属单位自有标识、须官方源文件，不自制仿绘）。
- 医院日常运营与行风汇报一律蓝分支；红分支只留给医院党建述职专题。

### ④ 特有禁忌
- 高校、医院忌企业化营销词：不写"赋能、抓手、闭环、打法、抢占市场"一类商业黑话，也不把学生 / 患者称作"客户"或"用户"——分别用"学生""患者（就诊群众）"；被主管部门挑出用词商业化是事业单位汇报最常见的减分项。

## 四、群团与行业协会（工会、共青团、妇联、工商联、行业协会商会等）

### ① 称谓与落款惯例
- **自称**：群团用组织简称（"市总工会""团市委"）；行业协会用"协会 / 本会"，涉及会员时用"会员单位"统称，不逐家点名于封面与总览（表彰页除外）。
- **排序**：封面层级为"组织全称 → 汇报名 → 服务对象关键词缎带"（如工会："服务职工 · 维护权益 · 建功立业"，一条封顶）；协会封面可加一行会员规模副题（"会员单位 XX 家"），数据须与总览页口径一致。
- **结尾页格式**：致谢居中（对会员单位 / 服务对象致谢可写进致谢句本身）；右下落款"组织全称 + 日期"，汉字数字与阿拉伯数字均可，但须与该组织历年材料保持一致，不中途换体例。

### ② 章节结构惯例
- **群团**：总览 → 服务对象工作分述（按人群 / 领域分，不按内设部门分）→ 品牌活动与典型案例 → 组织建设 → 问题 → 下一年度计划。案例页可配一张活动照片（照片带页型借 formal.md 章节页·蓝的横带构图），人物照片须为活动公开材料。
- **行业协会**：总览（行业运行数据先行）→ 行业服务（标准、培训、展会）→ 会员服务 → 行业自律与协调 → 问题 → 计划。行业数据必须标来源与口径注（如"据协会对 XX 家会员单位抽样统计"），无来源的行业数字不上页。
- 小标题句式：偏服务叙事，"对象 + 动作 + 成效"（如"职工维权：法律援助覆盖 XX 人次"）；忌用机关式的"全面加强、深入推进"作每章标题，群团与协会的标题要让人一眼看到服务对象。

### ③ 分支选择建议
- **群团首选党政红或政务蓝按场合分**：党代会、团代会等组织内正式会议与党建带团建主题用红分支（徽标与主题图由组织官方提供，守红线）；日常工作汇报、对外交流用政务蓝，避免规格过高。
- **行业协会一律政务蓝**：协会是社会组织不是党政机关，经营 / 服务汇报用红分支属规格错位；仅协会党支部党建述职可用红，且不与协会业务内容同册混排。

### ④ 特有禁忌
- 忌把服务对象写成管理口吻：群团与协会对职工、青年、企业是"服务 / 联系 / 引导"关系，标题与正文不用"管控、治理对象、落实到人头"式机关行政措辞；协会另忌替政府作审批性表态（"批准、核准"类词只出现在转述政府文件时）。
