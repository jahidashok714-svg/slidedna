# 产品包 · 变量扩展：品类扩展

与 `product.md` 配套使用：先按产品包定路线与组件语法，再按本文件按品类换招牌页与 imagery。色板、字阶强反差（展示字 72–96 pt ↔ 正文 10.5–12 pt）、一页一个主视觉的纪律不变，不因品类新造视觉体系。通用页（封面、章节、市场、结尾）照产品包配方执行，本文件只定义品类专属页。

## 智能硬件

**推荐路线：渐变发布（主）**——硬件新品靠光影与氛围造势，满版渐变 + 白巨字最能托住产品图的金属与玻璃质感；定价亲民的走量机型可改白底产品路线。

### 招牌页

1. **主视觉产品页（Hero 页）**
   - 构图：产品图占幅 ≥60%，从右侧或底边出血，压在渐变满版上；左侧只放眉题 + 一行巨字卖点（24–27 pt 粗体）+ 一行小字注，白字。
   - imagery：产品 45° 悬浮或斜置渲染/实拍图，深色或透明底以便压渐变；禁止白底电商图直接贴入。
2. **佩戴 / 使用场景页**
   - 构图：场景图满版出血，文字只在下缘一条：大题一行 + 说明一行；或左图右文，图占 55–65%。
   - imagery：真人佩戴/手持/家居使用中的实拍，人物面部可入镜但不抢产品；图占比 ≥55%。
3. **参数对照页**
   - 构图：沿产品包"产品对比页"语法——本代 / 上代（或本品 / 竞品）两列文字对位，中央竖轴串陶土色块改为本路线点缀色的图标方块作对比脊；每列只留 4–6 行关键参数（续航、重量、屏幕、芯片、防水、价格），数值用大百分比同级字号（24–36 pt）突出差异行，其余行正文字号；整页不做表格线。
   - imagery：两列列头各放一枚小产品图（占幅各 ≤15%），或整页无图、只靠字阶分胜负。

**文案语气与禁忌**：语气讲体验与体感（"轻 10 克""多撑两天"），参数翻成人话；**禁忌——参数对照页只准一页且只留关键差异，把完整规格表塞进发布 deck 是硬件 deck 最常见的翻车。**

## 软件 / App

**推荐路线：白底产品（主）**——界面本身就是产品，白/浅灰 `#F5F5F7` 底最能衬托 UI 的色彩与信息密度；强品牌色的 App 可局部借渐变路线做封面与章节页，内容页仍回白底。

### 招牌页

1. **界面展示页**
   - 构图：一台手机样机占幅 45–55%，从底边出血或居右；左侧大题 + 一段（≤3 行）讲这一屏解决什么问题；或三台样机横排成阵，每台下一行小字注，只讲一个流程。
   - imagery：真实 UI 截图装入样机框（不加边框不加阴影，照产品包纪律）；截图必须是当前版本真实界面，禁止用示意线框图冒充。
2. **功能矩阵页**
   - 构图：卖点页语法的软件版——2–4 行功能行交替排布，每行：糖果点缀色圆底图标徽章 + 粗体功能名（24–27 pt）+ 一行场景化说明 + 细下划线；免费/会员分层时用产品对比页语法两列对位，脊上图标方块标注版本差异。
   - imagery：无整图；图标徽章即视觉，或每行行尾配一枚 ≤15% 占幅的局部界面小图。
3. **数据成效页**
   - 构图：照产品包数据页——一图居中，环图/大百分比用白底路线糖果色序，名称 + 一行注配对（如留存、提速、节省时长）；不用坐标轴图表。
   - imagery：无图，靠色序与字阶。

**文案语气与禁忌**：语气讲场景与动作（"开会说完，纪要已经整理好"），功能名写成用户得到什么；**禁忌——只堆功能清单不落场景，是软件 deck 第一大忌；一页超过 4 个功能行必须拆页或砍。**

## 消费品（美妆 / 食品 / 家居）

**推荐路线：轻奢米白（主，美妆与家居）**——象牙米白 `#F3ECE5` + 陶土/深棕同色系最能传达质地与生活感，Jost + Gilda Display 双族的衬线展示字自带高级感；**食品例外走白底产品路线**——糖果点缀色衬食欲与口味区分，米白底压不住鲜亮食物图。

### 招牌页

1. **成分 / 卖点解构页**
   - 构图：产品图居中偏左占幅 40–50%（压米白底、无边框），3–4 条细线（1 pt）从产品向外引出，线端各接一个卖点：粗体卖点名（20–29 pt 轻奢页题规格）+ 一行小字注（成分名、含量百分比用 24–36 pt 大字单列）；引线布局左右交替，整页留白主导。
   - imagery：产品静物实拍，光线柔和、背景与米白底同调；禁止电商白底抠图感素材（与底色冲突时宁可用带场景的静物图裁切）。
2. **生活方式页**
   - 构图：场景图满版或占幅 ≥65% 出血，文字压在图内留白区或下缘：衬线大题一行 + 一行小字；发丝线框在本页收边（轻奢路线组件，按包规范路线内使用）。
   - imagery：真实生活场景（晨间梳妆台、餐桌一角、客厅午后），自然光、有人气但人物不抢镜；图占比 ≥65%。
3. **口味 / 色号 / 系列页（食品与美妆）**
   - 构图：3–4 个单品横排等距，每品下方：名称大写 + 一行注；食品走白底路线时各品压一枚糖果色圆底作味型区分，美妆走轻奢路线时只用陶土/棕三段分深浅，不引入新色。
   - imagery：单品图同角度同光线成组拍摄/渲染，单品占幅各 15–20%。

**文案语气与禁忌**：语气讲质地、气味、日常仪式感，用具体名词不用形容词堆砌；**禁忌——参数/成分表压过氛围图：成分只准解构页一页且以引线图解呈现，整页文字表格进消费品 deck 即破格。**

## 汽车与出行服务

**推荐路线：渐变发布（主，整车与新车发布）**——整车主视觉需要满版氛围与大字压场，渐变 + 白巨字是唯一能托住整车图的路线；**出行服务（网约车/共享/租车 App 类）转软件品类处理**，走白底产品路线与界面展示页，只在封面借整车/城市夜景图造势。

### 招牌页

1. **整车主视觉页**
   - 构图：整车图满版出血（占幅 100%），标题压至下缘：眉题 + 72–96 pt 巨字车名/主张 + 一行小字注；或 3/4 前侧方整车图居中、渐变满版托底，文字上压。
   - imagery：整车实拍/官方渲染，低机位、侧逆光，背景为公路/城市夜景/极简影棚；禁止经销商展厅随拍图。
2. **续航 / 安全数据页**
   - 构图：照产品包数据页与市场页语法拼合：一页只讲一个数——24–36 pt 以上大数字居中（如 CLTC 续航 km、充电分钟数），名称 + 一行注配对，注里写清测试工况；多个数必须拆页或降为卖点行，禁止把工信部参数表整页搬入。安全页用环图呈现测试评级构成时，扇区用本路线点缀逻辑（渐变路线无第三色，用白色深浅阶）。
   - imagery：无整图，或下缘一条 ≤20% 占幅的公路/充电场景横幅图。
3. **座舱 / 场景页**
   - 构图：内饰图满版出血，文字下缘一条大题 + 一行说明；或左右分栏，图占 55–65%，文字侧只放一个卖点（座椅/屏幕/空间三选一）。
   - imagery：座舱实拍，屏幕点亮状态、自然光从车窗入；人物可入镜（驾驶/后排乘坐），不摆拍广告脸。

**文案语气与禁忌**：语气讲路况与旅程（"满电出发，中间不进服务区"），数字必带工况口径；**禁忌——续航与加速数字不标工况即视为虚标，本包内一律不许裸奔；整车 deck 里出现坐标轴图表与参数大表，同样破格。**
