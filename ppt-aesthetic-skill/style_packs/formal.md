# 风格包 · 正式汇报（formal）

适用场景：党政机关 / 国企 / 大型组织的工作汇报、总结汇报。庄重仪式感，微软雅黑统一全册。数值来源：党政红 + 政务蓝·大气 + 政务蓝·框架三套参照拆解报告。

## 分支与色彩（二选一，一册一色相家族）

| 分支 | 主色 | 辅色 / 底 | 纪律 |
|---|---|---|---|
| 党政红 | `#AC0000` | 深红 `#6C0000`、亮红 `#C00000` / `#DE0000`、环图残段浅粉 `#FFAFAF`；底图暖米色调 | 红只用红家族，不引第二色相；金色只给徽标 |
| 政务蓝 | `#0070C0`（标准蓝）或 `#4F91A0`（青蓝，二选一） | 浅蓝 `#2B83E5` / `#00B0F0`、深藏青（徽章）、浅灰底 `#F2F2F2` 系 | 标准蓝偏政务、青蓝偏企业汇报，不混 |

正文色：红分支 `#4D4D4D`；蓝分支 `#262626`，标题深灰 `#3A3A3A` 可用。

## 字体与字号梯度

- 中文字体：微软雅黑全册统一，标题可加粗；不用宋体、不用书法体。
- 西文 / 数字：Calibri Light 或 Century Gothic 系；封面年份大数字可用 Impact 类窄体（青蓝分支样本做法）。
- 封面年份数字：特大（≥72 pt 级，全页最大元素）；封面标题 32–44 pt 粗体；页标题 16 pt 粗体主色、左上；正文 12 pt（高密度）～14 pt；条目小题 13–14 pt。

## 页型配方

| 页型 | 构图配方 |
|---|---|
| 封面·红 | 全幅主题照片底图 + 顶部居中徽标 + 黑粗标题居中 + 主色缎带横幅（白字单位 / 汇报名）——徽、题、缎带仪式三件套 |
| 封面·蓝 | 浅灰底；大数字年份 + 主色粗标题居左；关键词缎带条一条；右上斜向菱形图阵（框架样本做法，可选）或底部波浪线群（大气样本做法） |
| 目录 | 章节号用主色徽章（红：缎带书签；蓝：圆 / 菱形），一行一章 |
| 章节页·红 | 与封面同底图，徽章 + 主色大字章名 + 细线 + 副题，居中偏上，下半页留给底图 |
| 章节页·蓝 | 全宽照片横带 + 深色圆徽章压照片一角（白字章名）+ 下方正文 |
| 内容页·红 | 全幅底图留边 + 白色内容卡内嵌；页眉：小徽标 + 主色粗标题压在底图带上 |
| 内容页·蓝 | 浅底，页标题左上主色粗体；左图右文（图约 1/3 幅）或条目式（一段文字 + 一条细主色分隔线） |
| 数据页 | 红：原生环图三列（主红 + 浅粉残段双色环，环心百分比）；蓝：形状仪表盘单色刻度，或圆组件 + 加号连接 |
| 结尾页 | 与封面同底图 / 同底色，一句致谢居中 |

## 组件语法

- 徽章：红用缎带书签形（下端燕尾），蓝用正圆 / 菱形；一律主色满填 + 白字数字 / 章名。
- 缎带条：主色满填横条 + 白字关键词（封面专用，一册一条）。
- 分隔线：主色细线 0.75–1 pt（条目分隔、标题下划线）。
- 内容卡：仅红分支用——白卡无阴影、四角直角，压在照片底图上，卡边距均匀留出底图一圈。
- 圆组件语法（青蓝分支）：主色圆（白图标 + 白字标签）以"+"号连接成行，段落可用主色直角拐线半框围住。

## 禁忌

- 不用渐变字、不用艺术字 / 书法体。
- 红分支不出现蓝 / 绿等第二色相（照片本身除外）；蓝分支不出现红色元素。
- 不用圆角阴影卡片堆叠。
- 正文页标题一律左上，居中只给封面与章节页。
- 不取"整页底图承载全部设计"的做法（样本 B1 的短板）：色板与组件语法可取，版式必须以可编辑形状重建。
