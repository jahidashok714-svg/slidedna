# 风格包 · 学术组会 / 答辩（academic）

适用场景：研究生组会汇报、论文答辩、科研进展汇报。白底深蓝顶会风，结论式标题，结构图与实验数据页是核心页型。
数值来源：Slidesgo《Robotics Technology Thesis》+ SciFig 组会模板 Minimal/Bold 拆解报告（v2_design_dna.md，65 项清单，已实测落地验证一轮）。画布基准 13.33 × 7.5 in（16:9）。

## 色板

| 角色 | 取值 | 纪律 |
|---|---|---|
| 主色 | 深蓝 `#0F2A4A` | 标题、深色页底、终点强调 |
| 品牌蓝 | `#1F5FA8` | 图表主系列、标题强调 |
| 辅助青 | `#2EA8C0` | 只许出现在标题下短线与结构图节点点缀，不得与蓝色同面积并行抢主色 |
| 唯一强调 | 橙 `#D55E00` | 只点最优数据 / 关键数字，全册不出现第二个强调色 |
| 数据主色（备选系） | 深青 `#0F4C5C` | SciFig 系主色，可作整册主色替代 |
| 卡片浅底 | `#F4F5F7` | 卡片、结论带底 |
| 描边 | `#CFD9E0`（1 pt） | 替代阴影区分层级 |
| 图表网格 | `#E3E9ED` | 只留水平线 |
| 正文 | `#333D47` | — |
| 次级灰 | `#5A6B7D` | 眉题、图注、页脚 |

数据色板（Okabe-Ito，全套图表只用这一套）：`#0F4C5C / #D55E00 / #E69F00 / #56B4E9 / #009E73 / #F0E442`；常规双系列优先 蓝 `#1F5FA8` + 橙 `#D55E00`，必要时加青 `#2EA8C0`。

## 字体与字号梯度

- 字体：微软雅黑全册统一（源文件的教训是靠层级不靠字体；展示字体在接收方机器上不可靠，不用）。
- 封面标题 48 pt 粗体；页标题 28 pt 粗体；眉题 10.5 pt 灰（格式"02 · 方法与系统架构"，章节号 + 章名）；小标题 20 pt；正文 12.5–13.5 pt；图注 10.5 pt 灰；大数字 / 数字卡数字 36 pt；页脚 9.5 pt `#5A6B7D`；数据标签 13 pt 粗体。

## 版式基线

- 内容左基线 0.62 in，右界对称。
- 承载面构图：内容面板四边内缩约 3.5%，标题在面板内左上（10 in 画布实测距面板顶约 0.4 in），内容不贴边、不散在裸底上。
- 标题下短线：青 `#2EA8C0`，0.85 × 0.045 in，距标题基线 0.08 in，全册像素级一致。
- 每页必备：章节眉题 + 结论式标题（标题写成结论句，不写话题词）。

## 页型配方

| 页型 | 构图配方 |
|---|---|
| 封面 | 白底 + 左侧主色竖边；顶部小字单位名（左基线 0.62 in）；中部两行粗标题；底部双栏信息网格（姓名/职务 ‖ 课题组/日期）对齐收尾；可融一张主视觉图。深蓝全幅为变体，与谢谢页呼应 |
| 提纲 / 目录 | 编号胶囊徽章（浅灰蓝底 + 深蓝粗数字）→ 章节名粗体 → 一行 10 pt 说明，三级层级；行距紧凑不留大空白 |
| 背景页 | 双卡 `#F4F5F7` + 顶部 3 pt 主色线分工；副标题结论式；正文关键数字就地加粗着色；卡底可加"问题 → 对应章节页码"索引行 |
| 数字卡页 | 三卡横排，36 pt 数字居中成视觉中心、标签下移；卡顶各加 3 pt 主色线 |
| 结构图页 | 大容器描边无阴影；内部子框底色两档（编码器蓝系 / 解码器青系）；细线箭头约 2.25 pt；框左上角加序号点标讲解顺序；堆叠顺序须自下而上语义正确，必要时加方向箭头标阅读方向 |
| 图表页 | 图主文辅：左图约 55% 宽 + 右侧 callout 列（每条以约 4 pt 竖色条领起"标题 + 两行说明"）；或图文 45/55 分栏；每图下方必有 10.5 pt 灰色图注（画了什么 + 说明什么 + 数据来源） |
| 表格页 | 最优行高亮（浅蓝底）+ 左侧 4 pt 竖色条；表下结论带（浅蓝底横条：结论在前、评估口径小字在后） |
| 占位页（截图 / 案例） | 虚线描边占位框 + 角标，全册统一规格 |
| 问题讨论页 | 三卡横排（卡头深蓝条与卡身圆角衔接修正）+ 底部整行横带"希望得到的帮助 / 预期产出"；卡内条目行距 1.3 |
| 结论页 | 双卡底部对齐；计划改编号时间线（01/02/03 节点 + 事项 + 预计产出）；卡下加一行信息行（下期时间 / 本期交付物） |
| 谢谢页 | 深蓝全幅 + 居中大字（与封面呼应）；致谢行宽收至页宽 60% 居中；其下联系方式 / 课题组小字，形成"大字—致谢—联系方式"三级 |
| 组件库页 | 散件按本包规范定版：眉题、数字卡、虚线占位框、结论带、标签胶囊、竖色条 callout |

## 组件语法

- 卡片：`#F4F5F7` 浅底 + 顶部约 3 pt 主色线，无阴影；或 1 pt 描边 `#CFD9E0`。
- 胶囊徽章：浅灰蓝圆角胶囊 + 深蓝粗数字（目录 / 分节编号系统）。
- 图表：网格只留水平线 `#E3E9ED`；曲线 2.25 pt；图例移入图内；系列色按数据色板顺序。
- 占位框：虚线描边，全册统一。
